# Корпоративная оценка и M&A

> Главный вопрос корпоративной оценки: **сколько стоит компания**? Этот вопрос возникает при продаже бизнеса, привлечении инвестиций, IPO (Initial Public Offering — первичное публичное размещение акций), при покупке доли у партнёра, при оценке поглощений (M&A — Mergers & Acquisitions — слияния и поглощения). Существуют 4 основных подхода: DCF (Discounted Cash Flow — дисконтированный денежный поток), мультипликаторы, прецедентные сделки, по активам (asset-based). Они дают разные числа, и серьёзный анализ использует **все четыре** для получения диапазона оценки.

## 1. DCF — Discounted Cash Flow

### 1.1 Контекст и идея

**DCF (Discounted Cash Flow — модель дисконтированных денежных потоков)** — самый теоретически правильный метод оценки. Логика: **компания стоит столько, сколько денег она сгенерирует в будущем, приведённых к текущему моменту через ставку дисконтирования**.

DCF — **внутренний** метод оценки: не зависит от рыночных настроений, оценивает фундаментальную ценность.

### 1.2 Общая формула

```
Enterprise Value = Σ [ FCF_t / (1 + WACC)^t ] + Terminal Value / (1 + WACC)^T
```

Где:
- **FCF_t** — Free Cash Flow в год t
- **WACC** — стоимость капитала (см. [[03-Capital-decisions|заметку 03]])
- **Terminal Value** — стоимость в конце прогнозного периода (бесконечный поток после года T)

### 1.3 Прогноз Free Cash Flow

**FCF to Firm** (для оценки Enterprise Value):

```
FCF = EBIT × (1 − T) + D&A − ΔWorking Capital − CAPEX
```

Стандартный горизонт прогноза — **5-10 лет**, в зависимости от:
- Зрелости компании (молодая → длиннее прогноз)
- Предсказуемости индустрии (регулируемая электроэнергетика — regulated utility → длиннее; tech → короче)
- Стабильности денежного потока

### 1.4 Terminal Value — критическая часть DCF

После прогнозного периода считается **Terminal Value (TV — терминальная стоимость)** — оценка всего будущего потока за пределами горизонта.

**Два метода:**

**Gordon Growth Model** (модель Гордона — бесконечный рост с постоянным темпом):

```
TV = FCF_(T+1) / (WACC − g)
```

Где **g** — устойчивый долгосрочный темп роста (обычно 2-3%, не выше темпа роста ВВП).

**Exit Multiple** (через мультипликатор выхода):

```
TV = EBITDA_T × Exit Multiple
```

Где Exit Multiple — типичный для отрасли EV/EBITDA (например, 8x).

**Главная опасность:** Terminal Value часто составляет **60-80%** всей оценки. Маленькое изменение в g или WACC даёт огромное изменение в TV → во всей оценке.

**Ключевой вывод 1.4.** DCF теоретически правильный, но **очень чувствителен** к предпосылкам. Анализ чувствительности обязателен. На практике сложно сделать DCF, которому **доверяют** все — поэтому одного метода никогда не достаточно.

### 1.5 Enterprise Value vs Equity Value

После DCF получается **Enterprise Value (EV — стоимость предприятия)** — оценка всей операционной части бизнеса.

**Конвертация в Equity Value (стоимость для акционеров):**

```
Equity Value = Enterprise Value − Net Debt
            = EV − (Total Debt − Cash)
```

При оценке для покупки доли акционеров → нужен Equity Value.
При оценке для M&A целого бизнеса → используется EV.

**Ключевой вывод 1.5.** Различение EV и Equity Value — главный момент при чтении отчётов об оценке (valuation reports). Дом, обременённый ипотекой, дешевле «свободного» на сумму ипотеки — то же с долговой нагрузкой для компании.

### 1.6 Когда DCF работает / не работает

**Работает:**
- Зрелые компании с предсказуемым денежным потоком
- Стабильные облигационно-подобные (bonds-like) компании — коммунальные службы (utilities), регулируемые индустрии
- Компании, которые уже генерируют положительный FCF

**Не работает (или нужны костыли):**
- Стартапы (нет FCF, всё в Terminal Value)
- Циклические индустрии (cyclical) — средний (average) эффект сложно нормализовать
- Высоковолатильные тех-компании — прогноз слишком неопределён
- Компании в реструктуризации (restructuring) или кризисном состоянии (distress)

**Ключевой вывод 1.6.** DCF — мощный инструмент **для зрелых стабильных компаний**. Для растущих стартапов и циклических бизнесов больше работают мультипликаторы и прецеденты.

## 2. Multiples — мультипликаторы

### 2.1 Идея

**Multiples (мультипликаторы)** — это **относительная** оценка: «эта компания должна стоить как сопоставимые, плюс премия за уникальность / минус скидка за слабость». Логика: «если AAA торгуется на 12x EBITDA, то похожая BBB должна торговаться около 12x ± дельта».

Это **рыночный** метод: использует текущие цены публичных компаний (trading multiples — торговые мультипликаторы) или цены прошлых сделок (transaction multiples — мультипликаторы сделок).

### 2.2 Главные мультипликаторы

**EV / EBITDA** — отношение стоимости предприятия к EBITDA:
- Самый популярный мультипликатор
- Не зависит от структуры капитала и налогового режима → удобно для межстранового сравнения (cross-country comparison)
- Бенчмарки: 5-7x для традиционной розницы, 10-12x для технологических компаний, 15-20x для премиум-tech-growth (быстрорастущих премиум-tech)

**EV / Sales (EV / Revenue)** — отношение стоимости предприятия к выручке:
- Используется, когда компания не показывает положительной EBITDA (стартапы, гиперрост — hyper-growth)
- Бенчмарки: 0.5-1x для commodity-розницы, 2-5x для дифференцированных брендов, 10-20x для быстрорастущих SaaS

**P / E** (Price to Earnings — цена к прибыли):
- Основан на собственном капитале (equity-based), не на EV
- Бенчмарки: 10-15x для зрелых компаний, 20-30x для растущих, 50+ для гиперроста (с риском)

**P / B** (Price to Book — цена к балансовой стоимости):
- Для финансовых компаний (банки, страховые), где активы — главная ценность
- Бенчмарки: 1-2x для зрелых банков, < 1x — стресс-сигнал

**EV / NTM EBITDA** (NTM — Next Twelve Months — следующие 12 месяцев):
- На основе перспективной EBITDA (forward-looking — прогноз на 12 месяцев вперёд)
- Считается более релевантным, чем по последним фактическим данным (trailing)

### 2.3 Процесс мультипликаторного анализа

1. **Подбор сопоставимых компаний (comparable companies / compset)** — найти 5-10 публичных аналогов по размеру, индустрии, географии
2. **Расчёт мультипликаторов** — собрать EV / EBITDA, P / E и т.д. для каждой
3. **Выявление выбросов (outliers)** — убрать аномалии (компании в кризисном состоянии, цели M&A с премией)
4. **Диапазон** — обычно используется диапазон между 25-й и 75-й перцентилью (исключая хвосты)
5. **Применение к цели (target)** — например, target EBITDA × медианный мультипликатор = подразумеваемая оценка (implied valuation)

### 2.4 Премия и скидка

К базовой оценке по сопоставимым применяются корректировки:

**Premium (надбавка):**
- Контрольный пакет (control premium 20-30%) — за возможность управлять компанией
- Стратегические синергии (если покупатель стратегический — strategic, а не финансовый — financial)
- Высокий рост (growth) относительно сравнимых компаний
- Уникальные активы (бренд, патенты)

**Discount (скидка):**
- Скидка за ликвидность (liquidity discount, 10-30%) — частная компания (private) против публичной
- Скидка за миноритарную долю (minority interest discount)
- Скидка холдинговой компании (holding company discount) — за конгломератную структуру
- Стресс / кризисное состояние

**Ключевой вывод 2.4.** Мультипликаторы — это **якорь**, но финальная цена в M&A-сделке всегда корректируется на специфику. Профессиональные оценщики уделяют большое внимание именно обоснованиям премий и скидок.

### 2.5 Когда multiples работают / не работают

**Работают:**
- Зрелые публичные индустрии с большим числом сопоставимых компаний (розница, FMCG, промышленность)
- Активный M&A-рынок со свежими прецедентами

**Не работают:**
- Уникальные / монопольные компании (нет сопоставимых)
- Индустрии в драматических изменениях (drastic change) — мультипликаторы прошлого нерелевантны
- Гиперрастущие компании, где разница 5x → 50x на EBITDA в течение 2-3 лет

**Ключевой вывод 2.5.** Мультипликаторы — главный инструмент для оценки **первого приближения** (first-pass). DCF и мультипликаторы должны дать пересекающиеся диапазоны — иначе одна из оценок содержит ошибки.

## 3. Precedent Transactions — прецедентные сделки

### 3.1 Идея

**Precedent Transactions** (прецедентные сделки) — анализ цен **прошлых M&A-сделок** в той же индустрии. Логика: «вот за сколько похожие компании продавались за последние 3 года; это релевантный ориентир (benchmark)».

Отличие от мультипликаторов (trading comps — торговых аналогов):
- Trading multiples — текущая цена **публичных** акций (миноритарные сделки)
- Precedent transactions — цены **сделок поглощения** (с контрольной премией, синергиями)

Поэтому прецедентные сделки обычно дают **более высокую** оценку, чем торговые мультипликаторы.

### 3.2 Базы данных прецедентов

- **Bloomberg M&A** — самый полный источник
- **Mergermarket** — фокус на M&A глобально
- **Pitchbook** — венчур, рост и M&A
- **Reuters / WSJ** — открытые источники
- **Crunchbase** — для сделок в технологическом и венчурном сегменте

### 3.3 Процесс анализа

1. Подобрать 5-15 сопоставимых сделок за последние 3-5 лет
2. Собрать данные: EV, EBITDA, Revenue → мультипликаторы (EV/EBITDA, EV/Sales)
3. Корректировать на:
   - Размер сделки (мелкие сделки — small deals — имеют более высокий мультипликатор)
   - Стадию M&A-цикла (пик — peak — или дно — trough — рынка)
   - Стратегические vs финансовые покупатели (strategic vs financial buyers)
4. Применить медиану / диапазон к метрикам цели (target)

### 3.4 Когда precedent transactions работают / не работают

**Работают:**
- Активный M&A-рынок с регулярными сделками
- Зрелые индустрии с большим числом сопоставимых компаний
- Когда планируете M&A-сделку (прецеденты — самый релевантный ориентир)

**Не работают:**
- Уникальные сделки без прецедентов
- Резкие изменения рынка (прецеденты 2019 года нерелевантны для 2024)
- Новые индустрии без истории M&A

**Ключевой вывод 3.4.** Прецедентные сделки наиболее релевантны для **M&A-контекста**. Для публичного IPO больше работают торговые мультипликаторы (потому что инвесторы сравнивают с публичными аналогами — public peers).

## 4. Asset-Based Valuation — оценка по активам

### 4.1 Идея

**Asset-Based Valuation** — компания стоит как сумма её активов минус обязательства (то есть в первую очередь смотрит на **Balance Sheet**, не на P&L).

Два подхода:

**Book Value Approach** (подход по балансовой стоимости):
- Equity = Total Assets − Total Liabilities (из Balance Sheet)
- Используется для финансовых компаний и при оценке ликвидационной стоимости (liquidation value)

**Replacement Cost** (стоимость замещения):
- Сколько стоило бы воссоздать активы компании сегодня
- Используется для капиталоёмких индустрий (нефтегаз, недвижимость)

**Liquidation Value** (ликвидационная стоимость):
- Сколько компания будет стоить при «распродаже активов» (обычно сильно ниже Book Value из-за дисконта вынужденной распродажи — fire-sale)

### 4.2 Когда работает

- Финансовые компании (банки, страховые) — активы и есть основной бизнес
- Недвижимость — оценка через стоимость объектов
- Холдинги с разнородными активами
- Кризисные компании (distressed) — когда дальнейшее существование (going-concern) под вопросом
- Сравнение с ликвидационной стоимостью как «нижняя граница» оценки

### 4.3 Когда не работает

- Tech / SaaS компании — главная ценность в интеллектуальной собственности и команде, которые плохо отражаются в Balance Sheet
- Бренды и гудвилл (goodwill — деловая репутация) — бухгалтерский учёт (accounting) не отражает их полную стоимость
- Растущие компании — Book Value не отражает будущую прибыльную силу (future earnings power)

**Ключевой вывод 4.3.** Оценка по активам — **нижняя граница** оценки. Если компания торгуется ниже Book Value — это сильный сигнал либо кризиса (distress), либо недооценки (undervaluation), либо проблем с качеством активов.

## 5. Football Field — диапазон оценки

### 5.1 Идея

В сложных M&A-сделках разные методы дают **разные оценки**. «Football Field» («футбольное поле») — визуализация диапазонов от каждого метода, как полоски на футбольном поле.

Пример «футбольного поля» для оценки компании с EBITDA $50 млн:

| Метод | Диапазон |
|-------|----------|
| DCF | $400 млн − $550 млн |
| Торговые мультипликаторы (EV/EBITDA 9-12x) | $450 млн − $600 млн |
| Прецедентные сделки (EV/EBITDA 11-14x с премией) | $550 млн − $700 млн |
| По активам (стоимость замещения) | $250 млн − $300 млн |

**Цена сделки** обычно ложится в **пересечение** диапазонов от DCF и прецедентов (где-то $500 млн − $600 млн в этом примере).

**Ключевой вывод 5.1.** «Футбольное поле» — это **главная визуализация** профессиональной оценки. Показывает, что оценка — это **диапазон**, а не одно число; и где разные методы сходятся / расходятся.

## 6. M&A — процесс сделки

### 6.1 Полный цикл M&A

```
1. Strategic rationale (стратегическое обоснование) → Зачем покупаем (синергии, доступ к рынку, способности — capabilities)
2. Target identification (поиск целей) → Поиск кандидатов
3. Initial outreach (первичный контакт) → NDA (Non-Disclosure Agreement — соглашение о неразглашении), общая информация
4. Preliminary valuation (предварительная оценка) → Первичная оценка по публичным данным
5. LOI / Term Sheet (Letter of Intent — письмо о намерениях / term sheet — предварительное соглашение об условиях) → Рамочная договорённость
6. Due Diligence (комплексная предварительная проверка) → Глубокая проверка (финансовая, коммерческая, юридическая, операционная)
7. Final negotiation (финальные переговоры) → SPA — Sale & Purchase Agreement — договор купли-продажи
8. Closing (закрытие сделки) → Подписание, оплата, переход контроля
9. Integration (интеграция) → Слияние операций, культур, систем (100-day plan — 100-дневный план)
10. Post-merger review (постслияночный обзор) → Через 1-2 года: оправдались ли ожидания?
```

### 6.2 Due Diligence — четыре среза

**Financial DD (финансовая):**
- Качество прибыли (Quality of Earnings) — какая часть прибыли от основных операций
- Нормализация чистого оборотного капитала (Net Working Capital normalization)
- Долгоподобные обязательства (debt-like items) — пенсионные обязательства, аренда (leases), забалансовые статьи (off-balance-sheet)
- Налоговые риски (tax exposures)
- Достоверность прогноза (forecast credibility)

**Commercial DD (коммерческая):**
- Концентрация клиентов (customer concentration) — зависимость от топ-3 клиентов
- Рыночная позиция и доля рынка
- Силa ценообразования (pricing power)
- Конкурентный ландшафт (competitive landscape)

**Operational DD (операционная):**
- Производственные мощности (production capacity) и загрузка (utilization)
- Риски цепочки поставок (supply chain risks)
- ИТ-системы и интеграционные сложности
- HR — ключевые сотрудники (key persons), риски удержания (retention risks)

**Legal DD (юридическая):**
- Подверженность судебным рискам (litigation exposure)
- Проблемы с соответствием требованиям (compliance issues)
- Анализ договоров (contract review) — оговорки о смене контроля (change of control clauses)
- Принадлежность интеллектуальной собственности (IP — Intellectual Property — ownership)

**Ключевой вывод 6.2.** Due Diligence — **самая трудоёмкая** часть M&A-сделки. Большинство сделок «срываются» именно на DD, когда вскрываются проблемы, не видимые из публичных данных.

### 6.3 Synergy Analysis — анализ синергий

Покупатель часто платит **премию** к standalone valuation, обосновывая её **синергиями** — дополнительной ценностью от объединения.

**Revenue Synergies** (синергии выручки):
- Кросс-продажи (cross-sell) — продажа продуктов одной компании клиентам другой
- Географическая экспансия — выход на новые рынки через партнёра
- Ценообразование — устранение ценовых войн (price wars)

**Cost Synergies** (синергии затрат):
- Эффект масштаба в закупках (procurement scale) — лучшие цены поставщиков
- Устранение SG&A (Selling, General and Administrative — коммерческие, общие и административные расходы) — закрытие дубликатных функций (HR, finance, IT)
- Консолидация производства (manufacturing consolidation)
- Консолидация ИТ-систем

**Tax Synergies** (налоговые синергии):
- Перенос налоговых убытков на будущее (tax loss carry-forwards)
- Оптимизация трансфертного ценообразования (transfer pricing)

**Главная ошибка:** синергии выручки обычно **переоценены**, синергии затрат — **реализуются** в 60-80% случаев. Деловая практика — **дисконтировать** синергии выручки на 50%, синергии затрат на 20%.

**Ключевой вывод 6.3.** Большинство M&A-сделок **разрушают** ценность (исследования McKinsey показывают: 60-70% не оправдывают ожиданий). Главная причина — переоценка синергий и недооценка рисков интеграции (integration risks).

### 6.4 Integration — самая важная стадия

Сделку **закрывают** на стадии closing, но успех или провал определяется на стадии integration.

**Ключевые элементы интеграции:**
- **Day 1 readiness** (готовность к первому дню) — что должно работать с первого дня после закрытия сделки
- **100-day plan** (100-дневный план) — приоритетные интеграционные действия
- **Integration Management Office (IMO)** — офис управления интеграцией, отдельная структура, ведущая интеграцию
- **Cultural integration** (культурная интеграция) — самая сложная часть, особенно при трансграничных (cross-border) сделках
- **Talent retention** (удержание талантов) — удержание ключевых людей через бонусы за удержание (retention bonuses), пакеты акций (equity)

**Ключевой вывод 6.4.** Интеграция — **главный определяющий фактор** успеха M&A. Лучше переплатить на этапе сделки и хорошо интегрировать, чем купить дёшево и провалить интеграцию.

## Применение для руководителя — сводно

| Целевая роль | Главные применения |
|--------------|---------------------|
| **COO** | Участие в M&A due diligence (операционная часть); планирование интеграции (integration planning) после сделки |
| **Директор закупок** | Закупочные синергии в M&A; влияние слияния на базу поставщиков (supplier base) |
| **Директор продукта** | Синергии выручки через кросс-продажи; рационализация продуктового портфеля (product portfolio rationalization) после слияния |
| **CEO-трек** | M&A-стратегия; распределение капитала (capital allocation); переговоры с инвестиционными банками |
| **Финансовый аналитик** | Модели DCF / мультипликаторов / прецедентных сделок |
