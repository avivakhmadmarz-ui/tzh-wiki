# 01 — IBP и Connected Planning

> IBP (Integrated Business Planning — интегрированное бизнес-планирование) — это **расширение S&OP** до полной интеграции операций, финансов и стратегии. Connected Planning — современная парадигма 2020-х: planning в реальном времени через платформы (Anaplan, o9, Workday Adaptive) с AI-augmentation. Этот раздел — про эволюцию от классического S&OP к современному state-of-the-art.

## 1. Эволюция планирования

### 1.1 Историческая последовательность

![](attachments/diagrams/14-ibp-evolution.svg)

| Эра | Методология | Главная идея |
|-----|-------------|--------------|
| **1960-1980-е** | MRP / MRP II | Материальное и производственное планирование на mainframe |
| **1980-2000-е** | S&OP | Ежемесячное согласование спрос-поставка |
| **2000-2010-е** | IBP | Добавлены финансы и стратегия в S&OP |
| **2020-е** | Connected Planning | Интегрированное, real-time, AI-driven |

### 1.2 Главные различия

| Аспект | S&OP | IBP | Connected Planning |
|--------|------|-----|---------------------|
| **Горизонт** | 12-18 мес | 24-36 мес | 12-60 мес, multi-horizon |
| **Функции** | Sales, Ops | + Finance + Strategy | Все функции компании |
| **Цикл** | Monthly | Monthly + Quarterly | Continuous |
| **IT** | Excel + ERP | Specialized SCM | Platform (Anaplan, o9) |
| **Decision** | Operational | Tactical + Strategic | Strategic + Operational |

**Ключевой вывод 1.** Каждая следующая эра не **заменяет**, а **расширяет** предыдущую. IBP — это S&OP + финансы + стратегия, не вместо S&OP.

## 2. IBP — Integrated Business Planning

### 2.1 Концепция

IBP оформился в 2000-х благодаря **Oliver Wight** (компания) и её книге **«The Oliver Wight Class A Standard for Business Excellence»**. Цель — единый процесс планирования, интегрирующий **все плановые горизонты и функции** компании.

### 2.2 Пять шагов IBP-цикла

IBP сохраняет 5-шаговую структуру S&OP, но **расширяет каждый шаг**:

1. **Product Management Review** — портфель продуктов, NPI (New Product Introductions), pipeline
2. **Demand Review** — прогноз спроса + рыночные тренды + конкуренты
3. **Supply Review** — план поставок + capacity + supplier risks
4. **Integrated Reconciliation** — согласование с финансовым планом и стратегией
5. **Management Business Review (MBR)** — C-level принятие решений

### 2.3 Class A Standard

Oliver Wight определяет **Class A Companies** — компании с зрелым IBP:
- IBP — главный плановый процесс
- Все функции участвуют
- Financial integration — обязательна
- Performance management через IBP

Class A — это не сертификат, а **уровень зрелости**, оцениваемый через assessment.

### 2.4 Главные кейсы

- **P&G** — каноничный IBP-кейс, описан в книгах
- **Unilever** — глобальный IBP
- **Nestlé** — IBP как стандарт
- **Российские:** X5, Магнит — внедряют IBP с 2010-х

**Ключевой вывод 2.** IBP — следующая ступень зрелости после S&OP. Главное добавление — **финансовая интеграция** и **стратегический слой**.

## 3. Connected Planning

### 3.1 Концепция

**Connected Planning** — современная парадигма, продвигаемая Anaplan (основана 2008). Главные принципы:

- **One source of truth** — все плановые модели в одной платформе
- **Real-time** — изменения propagate мгновенно
- **Cross-functional** — sales, finance, supply chain в одной модели
- **What-if scenarios** — мгновенная симуляция альтернатив
- **AI-augmented** — ML в планировании

### 3.2 Главные платформы

| Платформа | Сильные стороны |
|-----------|-----------------|
| **Anaplan** | Лидер concept, mid-large enterprise |
| **o9 Solutions** | Modern architecture, knowledge graph |
| **Workday Adaptive Planning** | Сильная финансовая часть |
| **SAP IBP** | Интеграция с S/4HANA |
| **Pigment / Cube** | Современные SaaS-альтернативы |

### 3.3 Чем Connected Planning отличается от Excel

- **Excel:** static file, версии файла, ошибки формул, нет audit trail
- **Connected Planning:** centralized, real-time updates, governance, audit, multi-user collaboration

Главный момент перехода — когда Excel-сложность ломается под весом.

### 3.4 AI-augmentation

В 2024-2025 платформы добавляют AI:
- **ML-based forecasting** — лучше классических методов
- **NLP queries** — задаём вопросы в платформу на естественном языке
- **Anomaly detection** — автоматическое выявление отклонений
- **Recommendations** — система предлагает действия

**Ключевой вывод 3.** Connected Planning — это **технологический скачок**, как переход от ERP-monolith к cloud-native. Лидеры (Top 25) уже там; большинство компаний на 5-10 лет позади.

## 4. Внедрение IBP

### 4.1 Roadmap зрелости

| Уровень | Описание | Срок |
|---------|----------|------|
| **Базовый S&OP** | Месячный цикл, 5 шагов работают | 6-12 месяцев |
| **S&OP + Finance** | Финансовая интеграция | +6-12 месяцев |
| **IBP** | Полная интеграция, Class A path | +12-24 месяца |
| **Connected Planning** | Платформа + AI | +12-24 месяца |

Полный путь от MRP к Connected Planning — **3-7 лет**.

### 4.2 Главные ошибки

- **«Замена Excel на платформу без процесса»** — технология без зрелого процесса = быстрее ошибки
- **Игнорирование change management** — пользователи саботируют
- **Отсутствие executive sponsor** — IBP требует C-level commitment
- **Слабая data quality** — IBP «срабатывает» только на чистых данных

### 4.3 Best practices

- Сначала зрелость процесса, потом инвестиции в платформу
- Pilot на одной бизнес-единице
- Executive sponsor (CFO или COO)
- Independent assessment по Oliver Wight Class A

**Ключевой вывод 4.** IBP-трансформация — **3-7-летний путь**. Сократить не получается; лидеры (P&G, Unilever) проходили его 10-15 лет.

## Применение для руководителя

| Целевая роль | Главные применения |
|--------------|---------------------|
| **COO** | Стратегия IBP-трансформации; executive sponsorship |
| **CFO** | Интеграция бюджета и операционного планирования |
| **CIO** | Выбор платформы; data infrastructure |
| **Директор supply chain** | Daily IBP / S&OP цикл |
| **CEO** | Class A path как стратегическое решение |
