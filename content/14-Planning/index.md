## Зачем модуль руководителю

Каждая методология планирования — это **философия управления**, не просто «инструмент». Выбор между S&OP / IBP / DDMRP / Hoshin Kanri определяет:

- Как компания реагирует на изменения спроса
- Кто принимает плановые решения (центральный vs децентрализованный)
- Какой ритм управления (квартальный, месячный, недельный)
- Какие инструменты IT нужны
- Какую культуру строим

Большинство компаний используют **гибрид** — например, S&OP для tactical + Hoshin Kanri для strategic + DDMRP для операций. Понимание каждой методологии в отдельности — фундамент для построения собственной системы.

| **CEO** | Выбор философии планирования компании |

## Иерархия планирования

![](attachments/diagrams/14-planning-hierarchy.svg)

Зрелая компания имеет **иерархию** планов с разными горизонтами:

1. **Vision / Strategy** (5-10 лет) — стратегические цели
2. **AOP / Annual Plan** (1 год) — операционный план + бюджет (см. [[../02-Finance/05-Budgeting|модуль 02.05]])
3. **S&OP / IBP** (12-24 месяца, monthly) — согласование спрос-поставка
4. **MPS / Master Production Schedule** (3-12 месяцев, weekly) — график производства
5. **MRP / Procurement Planning** (1-12 недель, daily) — материалы, закупки
6. **Scheduling / Dispatching** (дни-часы) — операционные команды
