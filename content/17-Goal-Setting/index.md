# Модуль 17 — Goal Setting (целеполагание и метрики эффективности)

> Этот модуль покрывает **полный спектр методологий целеполагания** — от OKR (стартовый стандарт сегодня) до Hoshin Kanri (зрелая Lean-методология Toyota). Главный вопрос: какой метод выбрать под конкретный контекст компании? Включает встроенный подмодуль OKR-KPI (8 заметок) и 5 расширенных тем по другим фреймворкам.

## Заметки в модуле 17

1. **[[01-4DX|01 4DX (4 Disciplines of Execution)]]** — McChesney/Covey/Huling. WIG (Wildly Important Goals), Lead vs Lag measures, Compelling Scoreboard, Cadence of Accountability. Whirlwind vs WIG как главное напряжение. Не альтернатива OKR — операционная надстройка для исполнения.
2. **[[02-EOS-Rocks|02 EOS Rocks (Entrepreneurial Operating System)]]** — Gino Wickman. V/TO (Vision/Traction Organizer на 2 страницах), Rocks (квартальные приоритеты), L10 еженедельные встречи, Right People Right Seats (GWC). Целостная операционная система для 10-250 человек.
3. **[[03-V2MOM|03 V2MOM (Salesforce framework)]]** — Marc Benioff. Vision, Values, Methods, Obstacles, Measures. Главная особенность — обязательный каскад от CEO до individual contributor'а. Включает явное признание Obstacles.
4. **[[04-OGSM-Detailed|04 OGSM (Procter & Gamble)]]** — Objectives, Goals, Strategies, Measures. Классический корпоративный фреймворк FMCG-индустрии с 1950-х. Идеален для зрелых компаний с длинным стратегическим горизонтом. One Page Rule.
5. **[[05-Hoshin-Kanri-Deep|05 Hoshin Kanri Deep]]** — Toyota / Yoji Akao. Японская методология стратегической развёртки, интегрированная с Lean и PDCA. Catchball (диалоговый каскад), X-Matrix (визуальный документ), monthly reviews. Для зрелых производственных компаний.

## Какой метод выбрать?

![](attachments/diagrams/17-methods-comparison.svg)

| Контекст | Подходящий метод |
|---|---|
| Стартап / scale-up в tech | **OKR** |
| Стабильная операционная среда | **KPI** + Balanced Scorecard |
| Команда умеет ставить цели, но не исполняет | **4DX** |
| Small-mid бизнес (10-250) | **EOS** |
| Каскад от CEO до каждого сотрудника, values важны | **V2MOM** |
| FMCG / retail / зрелые корпорации | **OGSM** |
| Lean-зрелая производственная компания | **Hoshin Kanri** |
| Очень крупная корпорация | Hybrid — Hoshin Kanri / OGSM на уровне CEO + OKR на командах |

## Применение для руководителя

| Целевая роль | Главные применения |
|---|---|
| **CEO стартапа** | OKR как стандарт; 4DX для критического исполнения |
| **CEO small-mid** | EOS как целостная система; V2MOM если важны values |
| **CEO корпорации** | Hoshin Kanri / OGSM на executive-уровне |
| **CMO FMCG** | OGSM для маркетинговой стратегии |
| **COO производства** | Hoshin Kanri как часть Lean-системы |
| **Любой руководитель** | OKR + 4DX как стартовая комбинация |
