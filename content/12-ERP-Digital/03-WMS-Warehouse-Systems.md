# 03 — WMS — системы управления складом

> WMS (Warehouse Management System — система управления складом) — это **операционная система склада**, отвечающая за каждое движение единицы товара от приёмки до отгрузки. Без WMS склад работает «вручную» с потерями 10-30% производительности, ошибками в инвентаризации и низким fill rate. С WMS — точность 99.5%+, производительность кратно выше, видимость в реальном времени.

## 1. Что такое WMS и зачем она

### 1.1 Контекст и легитимность

WMS как класс систем оформился в 1990-х. Каноничная книга — **Gwynne Richards, «Warehouse Management»** (Kogan Page, 4-е изд. 2017). Стандарт обзора — **Gartner Magic Quadrant for WMS** (ежегодно).

В 2024 году глобальный рынок WMS — ~$4 млрд, растёт 14% годовых. Главный драйвер — рост e-commerce и автоматизация складов.

### 1.2 Зачем WMS, если есть ERP

ERP знает «сколько товара на складе», но **не знает где именно**. WMS добавляет:
- Адресное хранение (каждый паллет / ячейка имеет адрес)
- Маршрутизация комплектовщиков (оптимальный путь по складу)
- Контроль партий и сроков годности
- Real-time видимость движений
- Поддержка специальных потоков (cross-docking, kitting)

В большом современном складе (>5 000 м²) WMS — обязательна.

### 1.3 Главные функции WMS

- **Receiving (приёмка)** — приём товара от поставщика, сверка с заказом
- **Putaway (размещение)** — куда положить (оптимизация по правилам)
- **Replenishment (пополнение)** — перенос с верхних ярусов в пиковые
- **Picking (отбор)** — комплектация заказов клиентов
- **Packing (упаковка)** — упаковка для отгрузки
- **Shipping (отгрузка)** — отгрузка перевозчику
- **Inventory Management** — циклические инвентаризации
- **Returns (возвраты)** — обработка обратных потоков

**Ключевой вывод 1.** WMS — операционный центр современного склада. Производительность склада с / без WMS отличается в 2-5 раз.

## 2. Архитектура WMS

### 2.1 Контролируемое vs управляемое складирование

| Тип | Что значит |
|-----|------------|
| **Контролируемое** (Random storage) | WMS назначает любую свободную ячейку при размещении |
| **Управляемое** (Fixed storage) | Каждый SKU имеет свою ячейку (по правилам ABC, габаритам) |

В большинстве современных складов — гибрид: топ-ABC товары на фиксированных ячейках в пиковой зоне, остальные — random storage.

### 2.2 ABC-зонирование склада

- **Зона A** (топ-20% SKU = 80% отбора) — у пика, на удобной высоте, fixed
- **Зона B** (следующие 30% SKU = 15% отбора) — средняя доступность
- **Зона C** (50% SKU = 5% отбора) — верхние ярусы, дальние секции

Это даёт **минимальный путь комплектовщика** для большинства заказов.

### 2.3 Технологии отбора

- **Paper picking** — бумажные листы, базовый уровень
- **RF picking** — терминал сбора данных (TSD) со штрих-кодами
- **Voice picking** — голосовое управление, hands-free
- **Pick-by-light** — лампочки на ячейках показывают что отбирать
- **Pick-to-cart** — мобильные тележки с дисплеями
- **Automated picking** — роботы (AutoStore, Geek+, Quicktron)

### 2.4 Интеграции

WMS интегрируется с:
- **ERP** — мастер-данные, заказы, реализации
- **TMS** — отгрузки, документы
- **E-commerce** — заказы, статусы
- **Конвейеры / сортеры / роботы** — оборудование склада
- **WCS** (Warehouse Control System — система управления складским оборудованием) — слой между WMS и оборудованием

**Ключевой вывод 2.** Архитектура WMS определяется размером склада и уровнем автоматизации. Малый склад — RF picking + базовый WMS; крупный — voice + автоматизация + WCS.

### 3.2 Российский ландшафт

- **1С: WMS** — для интегрированного 1С-стека
- **СКЛАД 3PL** — российская специализированная платформа
- **Solvo WMS** — российская, многие крупные склады
- **Yard Management российские** — для управления территорией
- **Параллельный импорт SAP / Manhattan** — серая зона

- **OpenBoxes** — open-source WMS, актуально для гуманитарного сектора
- **Tryton WMS** — модули в Tryton ERP

### 3.4 Выбор WMS

| Размер склада | Рекомендация |
|---------------|--------------|
| До 1000 м² | Базовый ERP-функционал (1С) |
| 1000-5000 м² | Mid-market WMS (Solvo, Körber, Oracle) |
| 5000-50000 м² | Manhattan / Blue Yonder / SAP EWM |
| 50000+ м² | Manhattan / Blue Yonder + сильная кастомизация |

**Ключевой вывод 3.** Выбор WMS — стратегическое решение на 7-10 лет. Главные критерии: размер склада, уровень автоматизации, интеграция с ERP, бюджет.

## 4. KPI склада

### 4.1 Производственные KPI

- **Lines per hour** — строк отобрано за час комплектовщиком (стандарт: 80-120 для ручного отбора, 200+ для voice)
- **Orders per hour** — заказов в час
- **Pick accuracy** — точность отбора (целевая 99.5%+)
- **Dock-to-stock time** — время от приёмки до размещения (целевая 4-24 часа)

### 4.2 Качество

- **Inventory accuracy** — точность учёта (99%+ — обязательно)
- **OTIF** (On-Time In-Full) — заказов отгружено вовремя и в полном объёме
- **Damage rate** — % повреждённых при отгрузке
- **Returns rate** — % возвратов из-за ошибок склада

### 4.3 Затратные

- **Cost per order / per line** — себестоимость обработки
- **Storage cost per pallet/m²** — стоимость хранения
- **Labour productivity** — производительность персонала

### 4.4 Стратегические

- **Utilization** — загрузка склада (целевая 80-85%; выше — затыки, ниже — лишняя площадь)
- **Cycle time** — общее время обработки заказа

**Ключевой вывод 4.** Зрелая складская функция управляет 10-15 KPI. Без дашборда с этими метриками склад работает «по ощущениям».

## 5. Тренды автоматизации

### 5.1 Уровни автоматизации

| Уровень | Что включает | Когда применять |
|---------|--------------|-----------------|
| **Manual** | Бумажные листы, кладовщик ходит | Малый склад |
| **Mechanised** | Конвейеры, сортеры, TSD | Mid-size, стабильный поток |
| **Automated** | AS/RS (Automated Storage and Retrieval Systems), shuttles | Крупный склад |
| **Lights-out** | Полностью роботизированный, без людей | Очень крупный, e-commerce |

### 5.2 Современные технологии

- **AutoStore** (Норвегия) — кубический склад с роботами-шаттлами на верху. Сверхкомпактно, быстро. Российские: Wildberries использует
- **Geek+ / Quicktron** (Китай) — AMR (Autonomous Mobile Robots — автономные мобильные роботы) типа Kiva
- **Pickle Robot** — гуманоидные роботы для разгрузки контейнеров
- **Voice + AR** (Augmented Reality — дополненная реальность) — очки с навигацией

### 5.3 ROI автоматизации

Стандартные цифры:
- Производительность ×3-5 при полной автоматизации
- Снижение footprint ×2-3 (vertical density)
- Точность 99.9%+
- Окупаемость 3-7 лет при крупных объёмах

### 5.4 Когда НЕ автоматизировать

- Малые объёмы (< 1000 заказов/день)
- Сильная сезонность с пиками
- Высокая variability ассортимента
- Неустойчивый процесс (сначала оптимизировать, потом автоматизировать)

**Ключевой вывод 5.** Автоматизация — высокая отдача, но высокие риски. Внедрять после **процессной зрелости**, не вместо неё.

## 6. Внедрение WMS

### 6.1 Стандартный roadmap

| Фаза | Срок | Результат |
|------|------|-----------|
| Selection (выбор) | 2-3 месяца | Vendor + интегратор |
| Design | 2-4 месяца | Process blueprint |
| Configure / Build | 4-8 месяцев | Настроенная система |
| Test | 2-3 месяца | UAT, integration |
| Go-Live | 1-2 месяца | Production |
| Stabilization | 3-6 месяцев | Steady state |

Стандартный проект — 12-24 месяца от старта до stable production.

### 6.2 Главные риски

- Миграция данных (фактический stock не совпадает с системным)
- Сопротивление кладовщиков (привычка к старому)
- Производительность снижается на 30-50% в первые недели
- Интеграция с ERP — потенциальные расхождения

### 6.3 Best practices

- **Pilot warehouse** перед rollout на все
- **Train-the-trainer** для масштабного обучения
- **Strong cut-over plan** — детальный план перехода
- **Hypercare period** — усиленная поддержка первые 2-3 месяца

**Ключевой вывод 6.** WMS-внедрение — высокорисковая операция. Stop-the-warehouse моменты переключения требуют детальной подготовки.
