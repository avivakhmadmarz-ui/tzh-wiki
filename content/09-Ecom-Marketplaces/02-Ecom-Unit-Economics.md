# 02 — Юнит-экономика e-commerce

> Юнит-экономика e-commerce — это **полная картина одной транзакции / покупателя**: от валовой выручки через все вычеты к чистой марже, плюс расчёт пожизненной ценности клиента. Без её владения никакие операционные / маркетинговые решения нельзя обосновать. CAC / LTV — главные стратегические метрики.

## 1. Каскад маржи (Margin Waterfall) для e-commerce

### 1.1 Концепция

**Каскад маржи** — пошаговое раскрытие от валовой выручки до чистой маржи, показывающее **где деньги «уходят»**. Это критический инструмент для понимания прибыльности.

В рознице каскад маржи относительно простой. В e-commerce — существенно сложнее из-за множества дополнительных платежей.

### 1.2 Стандартный каскад e-commerce

![](attachments/diagrams/09-marketplace-economics-waterfall.svg)

Полная декомпозиция:

```
Валовая цена (как видит покупатель)          = 1 000 ₽
−  Комиссия маркетплейса (15%)               =   150 ₽
−  Эквайринг / обработка платежа (2%)        =    20 ₽
−  Логистика выполнения (FBO, 8%)            =    80 ₽
−  Платежи за хранение (FBO)                 =    30 ₽
−  Стоимость возвратов (20% × 200 ₽)         =    40 ₽
−  Реклама (15% TACoS)                       =   150 ₽
= Чистая выручка                              =   530 ₽

−  Себестоимость (COGS, 30%)                 =   300 ₽
= Маржинальная прибыль                       =   230 ₽ (23% от валовой цены)
```

### 1.3 Вариация по категориям

Сильно различается по категориям:

#### Fashion (высокие возвраты)

- Возвраты 30–40% — главный драйвер затрат
- Проблемы с размером, посадкой
- Вариации качества
- Разрывы между фото и реальностью

Чистая маржа обычно тонкая (5–15%).

#### Электроника

- Возвраты 5–10% (ниже)
- Высокий средний чек
- Важно доверие к бренду
- Ниже конкуренция в некоторых сегментах

Чистая маржа может быть 10–25%.

#### Beauty / Personal Care

- Возвраты 3–5%
- Средний чек средний
- Высокая повторная покупка
- Сильный потенциал лояльности

Чистая маржа обычно 15–30%.

#### Home / Household

- Возвраты 5–10%
- Переменный средний чек
- Менее зависим от бренда
- Практическая покупка

Чистая маржа 10–20%.

### 1.4 «Скрытые» затраты

Часто упускают:

- **Платежи за хранение накапливаются** для медленно движущихся
- **Затраты на брак / повреждения** в логистике
- **Потери от спорных транзакций**
- **Задержки оплаты / валютные** — на денежный поток
- **Затраты на соответствие** (сертификации и т.п.)

Зрелый продавец учитывает всё.

**Ключевой вывод 1.** Каскад маржи раскрывает «истинную экономику» каждой транзакции. Наивный взгляд («продал за X — валовая маржа Y») драматически недооценивает реальные затраты. Детальный каскад необходим для принятия прибыльных решений.

## 2. CAC — стоимость привлечения клиента

### 2.1 Определение

**CAC** (Customer Acquisition Cost — стоимость привлечения клиента) — стоимость привлечения одного нового покупателя.

```
CAC = (Маркетинговые расходы + Расходы на продажи) / Количество новых клиентов
```

### 2.2 Что включает

Комплексный CAC включает:

- Все платные размещения (Google Ads, реклама на маркетплейсах, в социальных сетях)
- Производство контента (если для привлечения)
- Платежи инфлюенсерам
- Зарплаты отдела продаж (если применимо)
- Партнёрские / реферальные платежи
- Маркетинговые инструменты / программное обеспечение в распределении

### 2.3 CAC по каналам

CAC сильно варьируется по каналам:

- **Органический поиск** — близко к нулю (но инвестиции в SEO)
- **Email-маркетинг** (существующий список) — низкий
- **Маркетплейс органический** — минимальный
- **Маркетплейс платный** — средний (5–20% TACoS)
- **Поисковая реклама (Yandex, Google)** — средний-высокий
- **Реклама в социальных сетях** — переменный, может быть высоким
- **ТВ / OOH (наружная)** — высокий, трудно атрибутировать

Оптимизация микса каналов — реальный стратегический вызов.

### 2.4 Отраслевые ориентиры

Типичный CAC для B2C e-commerce:

- FMCG / расходные: 200–1 000 ₽
- Одежда: 500–2 000 ₽
- Beauty: 400–1 500 ₽
- Электроника: 1 000–5 000 ₽
- Мебель / крупные товары: 2 000–10 000 ₽

Сильно варьируется, но эти диапазоны — отправные точки.

### 2.5 Новый клиент против повторного

Критическое различие:

- **CAC новых клиентов** (истинная стоимость привлечения)
- **Стоимость повторных заказов** (значительно ниже)

Средняя стоимость клиента смешивает оба. Раздельное отслеживание раскрывает истинную эффективность привлечения.

**Ключевой вывод 2.** CAC — фундаментальная маркетинговая метрика. Комплексное измерение (включая все каналы), сравнение с LTV — основа всех стратегических решений по привлечению.

## 3. LTV — пожизненная ценность клиента

### 3.1 Определение

**LTV** (Customer Lifetime Value — пожизненная ценность клиента) — суммарная прибыль от клиента за весь период отношений с компанией.

Несколько формул:

```
Простая: LTV = Средний чек × Частота покупок × Жизненный цикл клиента × Валовая маржа

Продвинутая: LTV = (Средняя месячная выручка с клиента × Валовая маржа %) / Месячный коэффициент оттока
```

### 3.2 Компоненты

#### 3.2.1 Средний чек (AOV — Average Order Value)

```
AOV = Общая выручка / Количество заказов
```

Зависит от:
- Цены
- Эффективности кросс- / апсейлов
- Стратегии бандлов

#### 3.2.2 Частота покупок

```
Частота = Общие заказы / Уникальные клиенты (год)
```

Зависит от:
- Природы категории (продукты — еженедельно, fashion — несколько раз в год)
- Программ лояльности
- Эффективности email / push-уведомлений

#### 3.2.3 Жизненный цикл клиента

Сколько клиент остаётся активным (покупает или вовлечён).

Привязан к:
- Удовлетворённости продуктом
- Лояльности к бренду
- Конкурентным предложениям
- Динамике категории

#### 3.2.4 Валовая маржа

Маржа на заказ. Из каскада маржи.

### 3.3 Пример расчёта

Данные клиента:

- AOV: 2 000 ₽
- Частота покупок: 4× в год
- Средний жизненный цикл: 3 года
- Валовая маржа: 30%

```
LTV = 2 000 × 4 × 3 × 0.30 = 7 200 ₽
```

Это прибыль с клиента за весь период отношений.

### 3.4 Продвинутые модели

#### LTV на основе когорт

Отслеживание реальных когорт со временем, аппроксимация кривых удержания, экстраполяция LTV.

#### Прогнозный LTV

Модели машинного обучения, предсказывающие LTV на основе раннего поведения.

Инструменты: Amplitude, Mixpanel, кастомная аналитика.

**Ключевой вывод 3.** LTV — стратегическая метрика, показывающая ценность клиента за пределами первой покупки. Высокий LTV оправдывает высокий CAC. Критично для стратегии роста.

## 4. Соотношение LTV / CAC и срок окупаемости

### 4.1 Соотношение LTV / CAC

Главная метрика эффективности:

```
Соотношение LTV / CAC
```

Ориентиры:

- **> 3:1** — здорово (отраслевой стандарт)
- **2–3:1** — нормально, но есть пространство для улучшения
- **< 2:1** — тревожно, вероятно убыточно
- **1:1** — точка безубыточности, рост невозможен
- **> 10:1** — возможно, недоинвестирование в рост

### 4.2 Срок окупаемости (Payback Period)

Сколько времени до возврата CAC через маржу:

```
Payback = CAC / Месячная валовая прибыль с клиента
```

Целевые значения:

- **< 6 месяцев** — отлично (быстрое возвращение, меньше оборотного капитала)
- **6–12 месяцев** — хорошо
- **12–18 месяцев** — приемлемо, но чувствительно к денежному потоку
- **> 18 месяцев** — рискованно, требует «глубоких карманов»

### 4.3 Применение

LTV / CAC определяет стратегию:

#### Высокое соотношение (> 3:1)

- **Больше инвестировать** в привлечение (есть пространство для прибыльного роста)
- **Тестировать премиальные каналы** (ТВ, OOH)
- **Агрессивное масштабирование**

#### Низкое соотношение (< 2:1)

- **Сначала улучшить LTV** (удержание, апсейлы)
- **Снизить CAC** (лучше таргетинг, органика)
- **Не масштабировать** расходы

### 4.4 Анализ на уровне канала

Разные каналы — разное LTV / CAC:

- Канал A: высокий CAC, высокий LTV (премиум-клиенты)
- Канал B: низкий CAC, низкий LTV (чувствительные к цене)
- Канал C: низкий CAC, высокий LTV (органика, сарафанное радио)

Лучшие каналы — типа Канала C, но их трудно масштабировать.

**Ключевой вывод 4.** Соотношение LTV / CAC + срок окупаемости — стратегическая финансовая рамка для e-commerce. Здоровое соотношение делает рост прибыльным; нездоровое означает проблемы бизнес-модели.

## 5. Экономика на уровне каналов

### 5.1 Типичный микс каналов

Компания e-commerce обычно работает с несколькими каналами:

- Маркетплейсы (WB, Ozon и др.)
- Собственный сайт
- Социальная коммерция
- Розница (если омниканальная)
- B2B

### 5.2 Сравнение каналов

Критично для стратегических решений. Типичное сравнение:

| Канал | Охват клиентов | Маржа | Потенциал LTV | Контроль бренда |
|-------|----------------|--------|---------------|-----------------|
| Wildberries | Высокий | Низкая | Низкий | Низкий |
| Ozon | Средний-высокий | Низкая | Низкий | Низкий |
| Собственный сайт | Низкий-средний | Высокая | Высокий | Высокий |
| Социальная коммерция | Переменный | Средняя | Средний | Средний |
| Розница | Высокий | Средняя | Средний | Средний |

### 5.3 Стратегические решения по каналам

**100% зависимость от маркетплейсов:**
- Большой охват, низкая маржа
- Ограниченные данные о клиенте
- Уязвимость к изменениям платформы
- Ограниченное построение бренда

**100% собственный сайт:**
- Высокая маржа, низкий охват
- Трудно / дорого привлекать трафик
- Полное владение данными
- Сильное построение бренда

**Гибрид (зрелый):**
- Маркетплейсы для объёма / охвата
- Собственный сайт для лояльных клиентов / построения бренда
- D2C для премиальных / эксклюзивных продуктов

Большинство стратегий со временем тяготеет к гибридному подходу.

### 5.4 Российская специфика

В РФ маркетплейсы доминирующе заняли рынок:

- 60–70% онлайн-розницы через 3–5 крупных маркетплейсов
- Собственный сайт работает хуже, чем в США / Европе
- Программы лояльности — на стороне маркетплейса (не бренда)

Стратегическое следствие: операции на маркетплейсе — обязательны; D2C — дополнение.

**Ключевой вывод 5.** Экономика каналов сильно различается. Стратегическое решение по миксу каналов критично. Российский рынок — доминируется маркетплейсами; серьёзные продавцы должны владеть маркетплейсами и рассматривать D2C как дополнение.

## 6. Промо-экономика

### 6.1 Промо-каскад

Специфический каскад для промо-периодов:

```
Стандартная цена:                    1 000 ₽
− Промо-скидка 30%                =    300 ₽
= Промо-цена:                          700 ₽

− Те же платежи (комиссия, логистика и т.д.)
= Ниже маржинальная прибыль

Но + увеличение объёма (например, 5–10×)
= Общая маржинальная прибыль может вырасти или упасть
```

Детальная математика требуется для каждого промо.

### 6.2 «Чёрная пятница» / большие распродажи

События маркетплейсов:

- **WB-распродажи** — несколько раз в год, могут быть скидки 50–70%
- **Большие распродажи Ozon** — крупные события
- **Yandex-распродажи** — ежеквартально

Участие обычно обязательно (штрафы за отказ).

Прибыльность на единицу резко падает; объём может компенсировать.

### 6.3 «Всегда включённые» промо

Фоновое дисконтирование:

- Кэшбек-предложения
- Скидки подписчикам
- Предложения для новых клиентов

Нужен тщательный расчёт — иногда снижают маржу без пропорционального объёма.

### 6.4 Тренд сжатия маржи

Критическая тревога:

- Конкуренция на маркетплейсах растёт
- Покупатели чувствительны к цене
- Промо-давление постоянное

Успешные продавцы либо:
- Достигают масштаба (компенсация объёмом)
- Переходят к премиум-позиционированию (более высокие цены)
- Усиливают бренд (менее чувствительные к цене клиенты)
- Вертикальная интеграция (более низкая себестоимость)

**Ключевой вывод 6.** Промо-экономика — нужна тщательная математика. Большинство «хороших промо-сделок» не приносят роста чистой маржи при корректном расчёте. Российский контекст маркетплейсов — давление постоянное; стратегический ответ критичен.

## 7. Прогнозирование и планирование

### 7.1 Прогноз продаж

Современный e-commerce использует машинное обучение:

- Шаблоны временных рядов
- Сезонные корректировки
- Влияние промо
- Внешние факторы (погода, праздники, новости)

Точность прогноза напрямую влияет на:
- Решения по запасам
- Планирование денежного потока
- Маркетинговый бюджет
- Планирование производства

### 7.2 Планирование запасов

Тесная связь между:

- Прогнозом продаж
- Целью «дней покрытия» (days of supply)
- Сроком поставки (lead time)
- Страховым запасом (safety stock)

Ошибки:

- **Недопрогнозирование** → дефицит, упущенные продажи
- **Перепрогнозирование** → застрявшие остатки, накопление платежей за хранение

### 7.3 Распределение маркетингового бюджета

На основе юнит-экономики:

- Каналы с высоким LTV — больше бюджета
- Каналы с низким CAC — масштабировать агрессивно
- Каналы с долгим сроком окупаемости — ограничивать инвестиции

Динамическое распределение через MMM (Marketing Mix Modeling — моделирование маркетинг-микса) и атрибуцию.

**Ключевой вывод 7.** Совершенство в прогнозировании / планировании — конкурентное преимущество. Современные лидеры e-commerce используют изощрённое машинное обучение; базовая компетенция достижима через структурированные модели в электронных таблицах.

## Сводный практический протокол

Месячный обзор экономики e-commerce:

| Период | Активности |
|--------|------------|
| Ежедневно | Отслеживание продаж / запасов |
| Еженедельно | ROI (Return on Investment — возврат на инвестиции) маркетинга; оптимизация рекламных кампаний |
| Ежемесячно | Анализ каскада маржи; обновление CAC / LTV |
| Ежеквартально | Стратегический обзор; решения по миксу каналов |
