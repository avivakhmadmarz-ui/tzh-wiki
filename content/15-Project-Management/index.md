# Модуль 15 — Project & Portfolio Management (управление проектами и портфелем)

> Доставка результата в **срок, бюджет, объём, ценность** — главное практическое умение современного руководителя. Модуль покрывает: Waterfall / PMBOK 7, Agile / Scrum / Kanban с подробным разбором цикла спринта и орг-структуры, R&D-практики вне ИТ (Stage-Gate, Lean Product Development, Set-Based Concurrent Engineering, APQP, V-Model), SAFe для крупных компаний, Portfolio Management, **ТРИЗ** (Теория Решения Изобретательских Задач — советский метод алгоритмического решения нестандартных задач) и **Design Thinking** (дизайн-мышление — user-centric подход к решению плохо определённых проблем).

## Заметки модуля

1. **[[01-Waterfall-PMBOK|01 Waterfall и PMBOK 7]]** — классический подход PMI (Project Management Institute — институт управления проектами), 10 областей знаний, EVM (Earned Value Management — управление освоенным объёмом), критический путь
2. **[[02-Agile-Scrum-Kanban|02 Agile / Scrum / Kanban и R&D-практики вне ИТ]]** — Agile Manifesto с переводом, подробный Scrum (3 роли, 5 событий, 3 артефакта, доска), орг-структура (мульти-командность, кто приоритизирует), Kanban с метриками потока, R&D-практики вне ИТ — Stage-Gate (Cooper), Lean Product Development (Reinertsen), Set-Based Concurrent Engineering (Toyota), APQP (автопром), V-Model (safety-critical)
3. **[[03-SAFe-Scaled-Agile|03 SAFe и масштабирование Agile]]** — SAFe (Scaled Agile Framework — масштабированный гибкий подход), LeSS, Spotify Model, для крупных компаний 50-1000+ людей
4. **[[04-Portfolio-PMO|04 Portfolio Management и PMO]]** — управление портфелем проектов, PMO (Project Management Office — офис управления проектами), governance, селекция
5. **[[05-TRIZ-Innovation|05 ТРИЗ]]** — Альтшуллер, ИКР (Идеальный Конечный Результат), все 40 принципов с примерами, АРИЗ-85С, законы развития систем
6. **[[06-Design-Thinking|06 Design Thinking]]** — IDEO, Stanford d.school, 5 этапов (Empathize / Define / Ideate / Prototype / Test), Double Diamond, инструменты каждого этапа, кейсы (IBM, SAP, Airbnb, Bank of America Keep the Change, GE Healthcare), гибрид DT + Lean + Agile

## Зачем модуль руководителю

Управление проектами — **универсальный навык**: ERP-внедрение, запуск продукта, реструктуризация, M&A integration — всё это проекты. Без проектного управления:
- Сроки срываются (70% IT-проектов, Standish CHAOS Report)
- Бюджеты превышаются в 2-3 раза
- Scope теряется
- Команды выгорают

Современный руководитель должен владеть **обоими подходами**: Waterfall для compliance-проектов, Agile для разработки. Гибрид — стандарт.

**ТРИЗ** — отдельная компетенция: советский метод **решения сложных задач**, который применим далеко за пределами инженерии — в бизнес-задачах, продуктовой стратегии, операционных проблемах.

## Применение для руководителя

| Целевая роль | Что взять из модуля |
|--------------|---------------------|
| **COO** | PMO governance; портфельный подход; selection критичных проектов |
| **CIO** | Agile в IT; SAFe для крупного IT; PMBOK для compliance |
| **Директор продукта** | Agile / Scrum daily; LeSS для масштабирования; Design Thinking для discovery |
| **Директор R&D / инновации** | ТРИЗ как инструмент изобретательства; Stage-Gate для NPI; Set-Based Engineering |
| **Главный инженер / Hardware-директор** | Stage-Gate, Lean PD, APQP, V-Model для физических продуктов |
| **CMO / Дизайн-директор** | Design Thinking для customer journey, продуктовых концептов, кампаний |
| **PMO Director** | Полный набор: PMBOK, Agile, Portfolio |
| **CEO** | Понимание PM-методологий для разговора с командой |
