# Модуль 21 — Legal & Compliance (юридический контур и соответствие)

> Цель — не стать юристом, но **прекратить подписывать слепо**. Юридическая грамотность для COO / директора закупок / любого executive. Модуль покрывает 4 главные области: договорное право РФ (структура договоров, существенные условия, заверения, форс-мажор), корпоративное право (ОСУ / СД / ЕИО, крупные сделки, сделки с заинтересованностью), трудовое право (приём / дисциплина / увольнение, NDA + коммерческая тайна, noncompete), compliance (антимонопольное, персональные данные, антикоррупционное, закон о торговле).

## Заметки модуля

1. **[[01-Contract-Law-RF|01 Договорное право РФ]]** — существенные условия (ст. 432 ГК РФ), структура коммерческого договора, заверения об обстоятельствах (ст. 431.2), заранее оценённые убытки (ст. 393.1), форс-мажор (ст. 401), рамочные и опционные договоры (ст. 429.1-429.3). Главные риски в шаблонах поставщиков.
2. **[[02-Corporate-Law|02 Корпоративное право]]** — виды юр. лиц (ООО, АО, ПАО / НПАО), иерархия корпоративных решений, полномочия и ответственность ЕИО (ст. 53.1 ГК РФ, Постановление ВАС № 62), крупные сделки, сделки с заинтересованностью, корпоративный договор.
3. **[[03-Labor-Law-for-Leader|03 Трудовое право для руководителя]]** — ключевые статьи ТК РФ (56-71, 81, 192-194, 240-249), приём / дисциплина / увольнение, материальная ответственность, защита коммерческой тайны через 98-ФЗ + режим КТ, почему noncompete слабо работает в РФ.
4. **[[04-Compliance|04 Compliance]]** — антимонопольное (135-ФЗ + ФАС), персональные данные (152-ФЗ + GDPR), антикоррупционное (273-ФЗ + FCPA + UK Bribery Act), закон о торговле (381-ФЗ). Compliance Officer как современная позиция.

## Зачем модуль руководителю

Юридическая грамотность — **базовая инфраструктура** управленческой работы. Без неё:

- **Договоры** подписываются слепо → скрытые риски накапливаются
- **Корпоративные решения** оформляются с нарушениями → оспаривание и личная ответственность
- **Увольнения** проводятся неправильно → восстановления и компенсации в судах
- **Compliance** игнорируется → штрафы и уголовная ответственность

Для **COO** и **директора закупок** юридическая грамотность особенно критична — на их подпись ежемесячно приходит десятки договоров на сотни миллионов рублей.

## Применение для руководителя

| Целевая роль | Что взять из модуля |
|---|---|
| **CEO / Founder** | Личная ответственность ЕИО (53.1 ГК РФ); compliance стратегия |
| **COO** | Daily работа с договорами; корпоративные процедуры; антимонопольные риски |
| **Директор закупок** | Договоры поставки; красные флаги в шаблонах; 381-ФЗ |
| **CFO** | Финансовые условия договоров; FCPA Books and Records |
| **CHRO** | Трудовое право; защита КТ; антикоррупционные тренинги |
| **General Counsel** | Полный модуль; основа для дискуссий с бизнесом |
| **C-suite candidate** | Базовая грамотность для разговора с юристом на равных |
