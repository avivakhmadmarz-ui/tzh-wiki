# 04 — Планограмма (Planogram) и управление пространством

> Полка / каталог — это **самый дорогой ограниченный ресурс ритейлера**. Решение о том, как распределить это пространство — стратегическое решение с прямым влиянием на выручку / прибыль. Планограмма — это формальная карта размещения товаров физически (магазин) или цифрово (электронная коммерция). Современное планограммирование — оптимизация на основе данных, опирается на просчитанную экономику полки.

## Карта раздела

![](attachments/diagrams/07-planogram-process.svg)

## 1. Что такое планограмма и зачем

### 1.1 Определение

**Planogram (планограмма)** — формальная диаграмма, показывающая **как продукты позиционируются на полке или в каталоге**. Определяет:

- Конкретные позиции для каждого SKU
- Количество facings (фейсингов — единиц, видимых покупателю)
- Соседние продукты
- Уровень полки (на уровне глаз, на уровне руки, нижний)
- Стандарты мерчандайзинга

Для физического ритейла — физическая карта полок. Для электронной коммерции — порядок продуктов на странице категории в каталоге, в результатах поиска, рекомендациях.

### 1.2 Зачем планограммирование

Без планограмм:

- Каждый магазин делает по-своему — несогласованность для покупателя
- Медленно оборачивающиеся SKU могут быть в премиальных позициях
- Бестселлеры буквально скрыты
- Возможности кросс-продаж упущены
- Stockout (отсутствие товара) из-за неадекватного количества фейсингов
- Споры с поставщиками о размещении

С планограммами:

- **Согласованность между магазинами** — покупатель находит те же вещи в тех же местах
- **Оптимизация выручки / прибыли** — лучшие позиции для лучших продавцов
- **Кросс-мерчандайзинг** — стратегические соседства
- **Предотвращение stockout** — фейсинги откалиброваны под скорость продаж
- **Управление поставщиками** — чёткие стандарты

### 1.3 Эволюция планограммирования

#### До 1980-х

Ручные раскладки, решения на уровне магазина, несогласованные.

#### 1980-2000-е

Развитие программного обеспечения:
- **Apollo** (раннее, простое)
- **Spaceman** (Nielsen)
- **JDA Software Plan-o-gram**
- **SAS Plan-o-gram**

#### 2000-2010-е

Интеграция с данными:
- Подача данных о продажах
- Данные о запасах
- Аналитика потоков покупателей
- Массовая кастомизация для кластеров магазинов

#### 2010-2020-е

ML / AI:
- Алгоритмы оптимизации
- Распознавание изображений для контроля
- Прогностическое тестирование раскладок
- AR (Augmented Reality — дополненная реальность) / VR (Virtual Reality — виртуальная реальность) для визуализации

#### 2020-е+

Эквиваленты для электронной коммерции:
- Алгоритмы ранжирования в поиске
- Движки рекомендаций
- Персонализированные раскладки каталога
- Динамическое упорядочивание

**Ключевой вывод 1.** Планограммирование — дисциплина управления самым ценным ресурсом ритейлера (пространство / размещение). Современное планограммирование уверенно основано на данных, интегрировано с ML. Электронная коммерция в равной мере нуждается в планограммировании, хотя в другой форме.

## 2. Процесс планограммирования

### 2.1 8-шаговое планограммирование

![](attachments/diagrams/07-planogram-process.svg)

#### 2.1.1 Шаг 1 — Сбор данных

Сбор данных:
- Продажи по SKU (единицы, выручка)
- Оборачиваемость запасов
- Маржа
- Срок годности (для продуктов питания)
- Физические размеры (высота, ширина, глубина)
- Вес (ограничения по нагрузке)

#### 2.1.2 Шаг 2 — Роль категории

Применить роль категории (Destination / Routine / Convenience / Seasonal — см. заметку 01). Категории с разными ролями получают разное распределение пространства.

#### 2.1.3 Шаг 3 — Распределение пространства

Определить, сколько общего пространства выделить каждому SKU.

**Распространённые методы:**

##### Days of Supply (дни запаса)

Пространство рассчитано на удержание X дней ожидаемых продаж.
- Плюс: избегает stockout
- Минус: может сильно недопредставлять медленно движущиеся товары

##### Скорость продаж

Пространство пропорционально темпу продаж.
- Плюс: согласовано с фактическим спросом
- Минус: не учитывает прибыль

##### Прибыль на фейсинг

Пространство пропорционально вкладу в прибыль.
- Плюс: прибыльные SKU получают больше пространства
- Минус: может недопредставить стратегические SKU

##### Fair share (справедливая доля)

Пространство соответствует доле в продажах / прибыли категории.

#### 2.1.4 Шаг 4 — Соседства (Adjacencies)

Где в категории каждый SKU размещён относительно других:

- **Дополняющие** — продукты, покупаемые вместе, размещаются рядом (макароны + соус, бритвы + крем)
- **Заменители** — конкурирующие SKU разнесены (чтобы покупатель тщательно сравнивал)
- **Премиальное позиционирование** — на уровне глаз для товаров с более высокой маржой
- **Якорные точки** — destination-SKU притягивают покупателей через категорию

#### 2.1.5 Шаг 5 — Создание планограммы

Формальный документ планограммы создаётся в специализированном ПО:

- Визуальное представление
- Спецификации (коды SKU, фейсинги, позиции)
- Инструкции по реализации
- Изображения / фото-референсы

#### 2.1.6 Шаг 6 — Валидация

Тестирование планограммы:
- Симуляция в магазине
- Макеты
- Пилотные магазины
- A/B-тестирование (если применимо)

#### 2.1.7 Шаг 7 — Реализация

Развёртывание в магазинах:
- Обучение команды магазина
- Поэтапное развёртывание
- Мониторинг соблюдения
- Координация с поставщиками

#### 2.1.8 Шаг 8 — Измерение

Отслеживание результатов:
- Изменения скорости продаж
- Влияние на маржу
- Частота stockout
- Обратная связь от покупателей
- Метрики соблюдения

Цикл обратной связи — улучшения в следующей итерации планограммы.

### 2.2 Частота

Типичные циклы планограмм:

- **Основной обзор** — ежегодно для большинства категорий
- **Ежеквартальные корректировки** — для сезонных или быстро меняющихся
- **Постоянные подстройки** — на основе данных об эффективности
- **Большой пересмотр** — при значительном изменении ассортимента

**Ключевой вывод 2.** 8-шаговый процесс планограммирования — дисциплина систематического управления пространством. Каждый шаг важен — пропуск (например, валидации) часто приводит к неоптимальной реализации. Зрелые ритейлеры имеют выделенные команды управления пространством, выполняющие этот процесс.

## 3. Экономика полки (Shelf Economics)

### 3.1 Метрики эффективности пространства

![](attachments/diagrams/07-shelf-economics.svg)

Современная экономика полки опирается на конкретные метрики:

#### 3.1.1 DPP — Direct Product Profitability (прямая прибыльность продукта)

**DPP** — прибыльность одного SKU после учёта **прямых затрат**:

```
DPP = Выручка от продаж
    − Себестоимость товаров (COGS)
    − Прямой труд (обработка, выкладка)
    − Прямые затраты на пространство (распределённая аренда)
    − Прямые прочие (потери, повреждения)
```

Отличается от валовой маржи, которая игнорирует операционные затраты. DPP даёт более ясную картину **истинной экономики SKU**.

#### 3.1.2 Прибыль на дюйм полки / см²

Прибыль на единицу физического пространства:

```
Прибыль на см² = Общая прибыль SKU / Площадь полки (см²)
```

Эта метрика напрямую сопоставима между SKU разных размеров — маленький SKU с низкой прибылью может опередить большой SKU с более высокой прибылью, если эффективнее использует пространство.

Самая решающая метрика для решений по распределению пространства.

#### 3.1.3 Скорость продаж (Sales Velocity)

Единиц продано за единицу времени. В сочетании с маржой даёт матрицу «скорость-маржа»:

- Высокая скорость, высокая маржа → идеально (устройства Apple в электронике, Coca-Cola в напитках)
- Высокая скорость, низкая маржа → рабочая лошадка (молоко, хлеб)
- Низкая скорость, высокая маржа → нишевая (luxury, специализированная)
- Низкая скорость, низкая маржа → неэффективные (кандидаты на удаление)

#### 3.1.4 GMROII — Gross Margin Return on Inventory Investment

```
GMROII = Валовая маржа $ / Средние запасы $

     = (Валовая маржа % × Продажи) / Средние запасы
```

Показывает **сколько маржи генерирует каждый рубль инвестиций в запасы**. Критично для оценки продуктов с разными профилями оборачиваемости и маржи.

GMROII > 200% = отлично.
GMROII 100-200% = хорошо.
GMROII < 100% = плохо, рассмотреть удаление.

#### 3.1.5 Category Fair Share (справедливая доля категории)

Сравнивает долю **выручки категории** vs долю **физического пространства**:

```
Fair Share = (Доля выручки категории) / (Доля пространства категории)
```

- **1.0** = сбалансированно
- **> 1.0** = недостаточно пространства (можно извлечь выгоду от большего)
- **< 1.0** = избыточно пространства (можно уменьшить)

Помогает выявить категории, нуждающиеся в перераспределении пространства.

### 3.2 Применение в решениях о пространстве

#### 3.2.1 Алгоритмы распределения пространства

Современное ПО оптимизирует:

```
Максимизировать: Σ (Прибыль на SKU × Выделенное пространство)
При ограничениях: 
- Общий лимит пространства
- Минимальные фейсинги на SKU (порог видимости)
- Ограничения соседства
- Лимиты на удержание запасов
```

Это линейное программирование или MIP (Mixed-Integer Programming — смешанно-целочисленное программирование) оптимизация.

#### 3.2.2 Распределение пространства между категориями

Внутри магазина, между категориями — та же логика:

- Каждая категория измеряется по DPP на квадратный метр
- Категории с более высокой прибылью на пространство получают больше пространства
- Иногда переопределяется стратегическими решениями (destination-категории получают дополнительное пространство)

#### 3.2.3 Непрерывная оптимизация

Современные ритейлеры регулярно обновляют планограммы на основе:

- Обновлений эффективности продаж
- Аналитики потоков покупателей
- Изменений в марже
- Новых продуктов

Подходы на основе ML позволяют непрерывное улучшение.

**Ключевой вывод 3.** Экономика полки даёт основу данных для решений о пространстве. Без отслеживания метрик распределение пространства сводится к интуиции / отношениям с поставщиками — оставляя значительную ценность нерасшифрованной. Зрелые ритейлеры педантично отслеживают DPP / GMROII.

## 4. Принципы визуального мерчандайзинга

### 4.1 Экономика уровня глаз

**«Eye-level is buy-level»** (на уровне глаз — на уровне покупки) — покупатели смотрят сначала на уровень глаз и берут оттуда гораздо чаще.

**Типичные уровни глаз:**

- Взрослые: ~155-175 см рост
- Дети: 75-130 см (важно для детских категорий)

Лучшие SKU идут на уровень глаз. Медленно движущиеся / низкая маржа идут выше или ниже.

### 4.2 Вертикальный мерчандайзинг

Рекомендация: **вертикальные полосы по подкатегории или бренду**.

Почему:

- Покупатель сканирует вверх / вниз внутри секции
- Та же подкатегория в вертикальной полосе легко сравнима
- Разные категории рядом позволяют сравнивать

Примеры:
- Туалетная бумага: вертикально по уровню качества (премиум → стандарт → эконом)
- Вино: вертикально по стране / региону

### 4.3 Блочный мерчандайзинг

Альтернатива: **горизонтальные блоки**, часто по бренду.

Когда полезно:

- Узнаваемость бренда высокая
- Покупатель ищет конкретный бренд
- Брендовый блок создаёт визуальный эффект

### 4.4 Массовая выкладка (Mass Display)

Один SKU в массивном количестве. Используется:

- Бестселлеры, особенно промо
- Сильный визуальный / коммерческий эффект
- Торцы стеллажей, концы рядов

Стоимость: забирает место с регулярной полки, но высокая коммерческая ценность.

### 4.5 Кросс-мерчандайзинг

Размещение связанных товаров вместе:

- Макароны с соусами
- Бритвы с кремом для бритья
- Вино с сыром

Цели:
- Увеличить размер корзины
- Обучить покупателей
- Удобство для покупательской миссии

Ограничение: слишком много кросс-мерчандайзинга создаёт путаницу.

### 4.6 Промо-выкладки

Специальные места для промо-товаров:

- **Торцы (end-caps)** — высокая видимость
- **Входы в ряды** — первое впечатление
- **Промо-стены** — концентрированные промо-зоны
- **Отдельно стоящие дисплеи** — привлекающие взгляд

Эти места обычно в 5-10 раз продуктивнее обычной полки, что оправдывает промо-инвестиции.

**Ключевой вывод 4.** Принципы визуального мерчандайзинга — практическая наука / искусство в сочетании. Экономика уровня глаз, вертикальные vs горизонтальные раскладки, кросс-мерчандайзинг — всё имеет измеримое влияние. Знание передаётся через обучение; интуиция без дисциплины оставляет деньги на столе.

## 5. Планограммирование в электронной коммерции

### 5.1 Цифровой аналог

В электронной коммерции «пространство» — это:

- **Порядок результатов поиска**
- **Раскладка страницы категории**
- **Виджеты рекомендаций («Покупатели также купили»)**
- **Особенности на главной странице**
- **Подсказки кросс-продаж (на странице корзины, checkout)**

Каждое — ограниченное, ценное «пространство», аналогичное физической полке.

### 5.2 Оптимизация алгоритма поиска

Большой компонент — алгоритм поиска:

- Какие SKU появляются в верхних результатах
- На основе: скорости продаж, рейтингов, маржи, промо-статуса, рекламы
- Поиск маркетплейса особенно чувствителен (алгоритм A9 у Amazon)

Для продавцов: **SEO + поисковая реклама** — получение лучшего размещения.
Для платформ: **ранжирование поиска** — стратегическое решение, влияющее на экономику категории.

### 5.3 Системы рекомендаций

Рекомендации «Покупатели, купившие X, также купили Y»:

- Коллаборативная фильтрация
- Прогнозы на основе ML
- Персонализация в реальном времени

Они приводят к значительной дополнительной выручке (Amazon приписывает рекомендациям 30%+ продаж).

### 5.4 Персонализация

Каждый покупатель видит несколько разный каталог:

- Персонализированные результаты поиска
- Персонализированные рекомендации
- Персонализированный контент главной страницы
- Иногда персонализированное ценообразование

Это создаёт **«планограмму на одного»** — полностью индивидуализированный опыт.

### 5.5 Специфика маркетплейсов

Маркетплейсы (Amazon, Wildberries, Ozon) имеют дополнительную сложность:

- **Продавцы конкурируют** за одно и то же размещение
- **Реклама интегрирована** (спонсируемые объявления)
- **Отзывы / рейтинги** влияют на ранжирование
- **Buy Box** конкуренция (для Amazon)

Категории на маркетплейсах требуют дополнительной экспертизы в цифровом мерчандайзинге.

### 5.6 Российская специфика

Эволюция Wildberries, Ozon:

- Развитые алгоритмы
- Активные промо-игры
- Внутренняя конкуренция между продавцами
- Специфические карточки товара — эквивалент SKU-страницы

Для продавцов цифровое планограммирование — работа на полный рабочий день для серьёзных операций.

**Ключевой вывод 5.** Планограммирование в электронной коммерции — равнозначно важное, технически более сложное, зависит от понимания алгоритма. Продавцы / категорийные менеджеры на маркетплейсах должны овладеть цифровым мерчандайзингом — это конкурентный дифференциатор.

## 6. Реализация и контроль соблюдения

### 6.1 Исполнение на уровне магазина

Планирование — только половина. Сложности исполнения:

- **Понимание командой магазина** — нужно знать, что делать
- **Ограничения по времени** — пополнение запасов, обновления планограмм занимают время
- **Представители поставщиков** — иногда имеют свои интересы
- **Нарушение потока покупателей** — крупные перестановки нарушают покупки

### 6.2 Обучение

Сотрудники магазина нуждаются в:

- Интерпретации планограммы
- Дисциплине пополнения
- Понимании важности соблюдения
- Стандартах для размещения новых продуктов

Регулярные программы обучения критичны.

### 6.3 Мониторинг соблюдения

Как проверить, что планограммы соблюдаются:

#### 6.3.1 Ручные аудиты

Визиты в магазины категорийными командами или аудиторами. Использовалось исторически.

#### 6.3.2 ИИ-распознавание изображений

Современный подход: Trax, Pensa Systems, Periodix используют компьютерное зрение:

- Делается фото полки
- ИИ идентифицирует SKU, позиции
- Сравнивает с планограммой
- Помечает расхождения

Обеспечивает масштабируемое, объективное измерение.

#### 6.3.3 IoT-датчики полки

Умные полки отслеживают уровни запасов в реальном времени. Используются в специализированных контекстах.

### 6.4 Метрики соблюдения

KPI:

- **% соблюдения планограммы** — % магазинов, правильно следующих
- **Время до соблюдения** — после обновления планограммы, скорость развёртывания
- **Частота stockout**
- **Время восстановления после OOS** (Out-of-Stock — отсутствия товара)

Цель: >95% соблюдения у зрелых ритейлеров.

### 6.5 Участие поставщиков

Крупные бренды часто предлагают:

- Бесплатные мерчандайзинговые команды (визиты в магазины)
- Кастомные дисплеи
- Бесплатное полочное оборудование
- Обучение для персонала магазина

Некоторые ритейлеры используют (партнёрство P&G / Walmart). Другие избегают (Trader Joe's, Costco) — независимость.

**Ключевой вывод 6.** Исполнение + соблюдение — определяют ценность планограммирования. Умная стратегия без дисциплины исполнения = напрасно. Современное распознавание изображений с ИИ революционизирует измерение соблюдения.

## Сводный практический протокол

Годовой цикл планограммирования для ритейлера:

| Период | Действия |
|--------|----------|
| Q1 | Основной обзор планограмм (категории А-уровня) |
| Ежеквартально | Корректировки на основе данных эффективности |
| Ежемесячно | Тактические обновления (промо, запуски новых продуктов) |
| Еженедельно | Аудиты соблюдения (распознавание изображений) |
| Ежедневно | Пополнение, реакция в реальном времени на stockout |

| Целевая роль | Что взять из заметки |
|--------------|---------------------|

| **Менеджер digital / e-commerce** | Оптимизация алгоритма; персонализация; размещение на маркетплейсах |
