# 03 — Платёжные коридоры

> После санкций 2022 года прямой банковский путь оплаты китайским / международным поставщикам стал проблематичным для большинства российских компаний. На текущий момент работают три основных направления: прямые расчёты через банки-исключения (Россия → КНР), агентские схемы через ОАЭ / Гонконг / Казахстан / Армению, и юаневые расчёты с использованием CIPS / СПФС. Это самая дорогая и быстро меняющаяся часть ВЭД.

## 1. Контекст 2022–2025

### 1.1 Что изменилось после февраля 2022 года

До февраля 2022 года российские компании оплачивали международные операции стандартным способом: рублёвый счёт → конвертация в USD / EUR → SWIFT-перевод иностранному поставщику через банк-корреспондент. Простая операция занимала 1–3 дня.

После 2022 года ситуация радикально изменилась:

- **Отключение от SWIFT** крупнейших российских банков (Сбербанк, ВТБ, Промсвязьбанк, Открытие, Совкомбанк, Новикомбанк, ВЭБ и др.)
- **Уход банков-корреспондентов** западных банков от обслуживания российских клиентов
- **Проверка на санкции** ужесточилась радикально — даже несанкционные банки тщательно проверяют сделки с РФ
- **Вторичные санкции** — риск для банков третьих стран, обслуживающих РФ
- **Платежи в USD / EUR** стали практически невозможны для многих компаний
- **Compliance-внимание** от китайских банков также выросло — многие отказываются принимать платежи из РФ

### 1.2 Эволюция за 2022–2025

| Период | Состояние |
|--------|-----------|
| Q1 2022 | Шоковый период, многие платежи замораживаются |
| Q2–Q3 2022 | Поиск работающих маршрутов, активизация ОАЭ / Гонконга |
| Q4 2022 – Q1 2023 | Установление новых паттернов; рост юаневых расчётов |
| 2023 | Стабилизация через 2–3 основных коридора; растущее использование CNY |
| 2024 | Ужесточение вторичных санкций; новые проблемы с Казахстаном / Арменией / Турцией |
| 2025 | Постоянная адаптация; смешанная картина с регуляторными изменениями |

### 1.3 Главная проблема

Главная проблема для российской компании сейчас — **предсказуемость платежей**. Платёж может «застрять» или быть возвращён через любой банк по соображениям соответствия. Это создаёт непредсказуемость, ухудшающую операционное планирование и отношения с поставщиками.

**Ключевой вывод 1.** Платёжные коридоры в торговле РФ–КНР — «движущаяся мишень», требующая постоянного мониторинга и нескольких резервных вариантов. Компания, опирающаяся на единственный канал, рискует операционным сбоем.

## 2. Прямые каналы — Россия → Китай

### 2.1 Какие банки работают напрямую

После санкций 2022 года список российских банков, способных делать прямые платежи в КНР (через банки-корреспонденты или CIPS), резко сократился. Топ-список (постоянно меняется):

- **ВТБ** — крупные операции, особенно через Дальневосточный филиал
- **Газпромбанк** — стратегический фокус на КНР, специализация на крупных операциях ВЭД
- **Россельхозбанк** — для сельхоз / коммодити
- **Альфа-Банк** — общая способность по ВЭД
- **МКБ** (Московский Кредитный Банк) — активно растёт в направлении КНР
- **Юаньский банк** (Russian-Chinese Investment Bank — Российско-Китайский инвестиционный банк) — специально для юаня (RMB)
- **Региональные банки Дальнего Востока** — Asia-Pacific Bank, Primorye Bank

Санкционный риск: банки, не находящиеся в санкционных списках сейчас, могут попасть позже. Команды соответствия российских компаний отслеживают обновления санкций ежемесячно или чаще.

### 2.2 Рабочие валюты

В прямых каналах работают:

- **CNY** (Chinese Yuan onshore — материковый юань) — основная валюта для платежей в КНР через CIPS
- **USD** — ограниченно, доступен только через очень небольшое количество банков, риск выше
- **EUR** — аналогично USD, ограниченно
- **AED** (UAE Dirham — дирхам ОАЭ) — через специализированные банки
- **CHF / TRY / другие** — для специфических маршрутов
- **RUB** — для трансграничных рублёвых платежей с китайскими партнёрами (например, через корреспондентов)

### 2.3 CIPS — Cross-Border Interbank Payment System

**CIPS** — китайская межбанковская платёжная система, альтернатива SWIFT в части юаневых расчётов. Запущена в 2015 году, активно расширяется.

CIPS позволяет российским банкам, имеющим прямые корреспондентские отношения с китайскими банками, осуществлять платежи в юанях без зависимости от SWIFT.

К 2025 году значительная часть торговли РФ–КНР проходит через CIPS, особенно для юаневых расчётов.

### 2.4 СПФС — Система Передачи Финансовых Сообщений

**СПФС** — российская система передачи финансовых сообщений Банка России, запущена с 2014 года как backup для SWIFT. После 2022 года СПФС активизировалась.

СПФС работает преимущественно внутри РФ, но также имеет интеграцию с CIPS (для юаневых расчётов) и с банками ЕАЭС / других дружественных юрисдикций.

### 2.5 Сложности прямых каналов

Несмотря на доступные маршруты:

- **Внимание соответствия** жёсткое — даже законные платежи могут «висеть» неделями
- **Банки ограничивают объёмы** — крупные платежи могут быть отклонены
- **Ежедневно меняющиеся требования** — требования к документации меняются
- **Ограниченный круг банков** — концентрационный риск

**Ключевой вывод 2.** Прямые каналы Россия → Китай работают для значительной части торговли, но с растущим трением. Российские компании должны выстраивать отношения с конкретными банками, имеющими возможность работы с КНР, и быть готовы к задержкам / отказам.

## 3. Агентские схемы

### 3.1 Зачем агентские схемы

Когда прямые каналы не работают (компания в санкционном списке, банк отказывает, специфическая ситуация), используются **агентские схемы** через третьи страны.

Логика: вместо прямого платежа Россия → Китай делается двухшаговая операция:

1. Россия → третья страна (ОАЭ / Гонконг / Казахстан / Армения)
2. Третья страна → Китай

Это легально и логистически работает, но **дороже** (комиссии агентов 2–7%) и медленнее (плюс день-два).

### 3.2 ОАЭ — Объединённые Арабские Эмираты

**ОАЭ** — самое популярное направление для агентских схем с 2022 года.

**Преимущества:**
- Стабильная юрисдикция, не в санкционных списках
- Сильные банки: ADCB (Abu Dhabi Commercial Bank), Mashreq, Emirates NBD, FAB (First Abu Dhabi Bank)
- Возможность работы в USD, EUR, AED
- Dubai International Financial Centre (DIFC) — финансовый хаб с хорошим регулированием
- Отличные отношения с КНР (торговля КНР–ОАЭ массовая)

**Недостатки:**
- Ужесточающаяся проверка KYC (Know Your Customer — знай своего клиента) / AML (Anti-Money Laundering — противодействие отмыванию) после 2023 года
- Банки могут отказывать в зависимости от источников / получателей
- Комиссия 2–5% обычно
- Сотрудники соответствия банков ОАЭ могут запросить обширную документацию
- Банковские праздники могут задержать платежи

**Операционные маршруты:**
- РФ → агент в ОАЭ → поставщик в КНР
- Агенты в Дубае: специализированные торговые компании, экспедиторы с финансовыми сервисами

### 3.3 Гонконг (Hong Kong)

**Гонконг** — традиционный финансовый хаб для торговли с КНР, но после 2022 года ситуация осложнилась.

**Преимущества:**
- Банки топ-класса (HSBC, Standard Chartered, Bank of China HK)
- Special Administrative Region (Особый административный район) — отдельная регуляторная рамка от материковой КНР
- Крупный финансовый центр с глубокими связями с КНР
- Операции в USD / HKD / CNH (офшорный юань)

**Недостатки:**
- HSBC, StanChart жёстко применяют стандарты соответствия (включают западные санкционные стандарты)
- Многие банки отказывают в работе с клиентами, связанными с РФ
- Местные банки Гонконга становятся более осторожными
- 2023–2024 — ужесточение

**Статус 2025:** Гонконг всё ещё используется, но преимущественно через государственные банки КНР (Bank of China, ICBC HK) с устоявшимися отношениями.

### 3.4 Казахстан / Кыргызстан / Армения (ЕАЭС)

Страны ЕАЭС (Евразийский экономический союз) — Казахстан, Кыргызстан, Армения, Беларусь — имеют таможенный союз с РФ.

**Преимущества:**
- Близость к РФ, схожая регуляторика
- Общее пространство с РФ
- Простые транзакции в некоторых валютах
- Комиссия ниже (1–3%)
- Менее жёсткое соответствие для российских клиентов

**Недостатки:**
- **Риск вторичных санкций** — особенно после 2024 года
- Банки начинают отказывать или ограничивать операции с РФ
- Казахстанские банки (Халык, БЦК, Forte Bank) после 2024 года пересматривают отношения
- Реже работают в USD; чаще в KZT, RUB, AED, CNY

**Статус 2025:** ещё используются, но с осторожностью. Концентрация в нескольких конкретных банках со стабильными отношениями.

### 3.5 Другие юрисдикции

Менее популярные, но используемые:

- **Турция** — для специфических маршрутов, осложнено соответствием
- **Вьетнам, Индия** — для локальных торговых маршрутов с КНР
- **Сербия, Беларусь** — для специфических операций
- **Израиль** — несколько банков с ориентацией на КНР

Каждый из этих маршрутов имеет свои особенности и меняющийся ландшафт.

### 3.6 Криптовалютные маршруты

**Криптовалюта** (USDT / Tether, USDC) — альтернатива для определённых операций.

**Преимущества:**
- Не требует традиционного банкинга
- Более быстрые транзакции
- Не подпадает под прямые санкции SWIFT

**Недостатки:**
- **Не соответствует 173-ФЗ** — нельзя оформить как стандартную валютную операцию
- Высокая волатильность USDT в стрессовых ситуациях
- Сложности с отчётностью
- Контрагентский риск (биржа может обанкротиться)
- Юридическая «серая зона» в РФ

**Статус:** некоторые компании используют для меньших транзакций, но это не общепринятая практика. Регулирование меняется в 2024–2025 (рамка криптовалют в РФ — в работе).

**Ключевой вывод 3.** Агентские схемы через ОАЭ / Гонконг / Казахстан / Армению — основной обходной путь для российских компаний под санкциями. Каждое направление имеет свои плюсы, минусы, риски. Зрелые компании имеют отношения в 2–3 коридорах для устойчивости.

## 4. Третьи стороны — договорная структура

### 4.1 Что такое «платёж через третье лицо»

![](attachments/diagrams/06-third-party-payment-scheme.svg)

Стандартная структура:

- **Резидент РФ (импортёр)** — должен китайской фабрике
- **Агент в ОАЭ / Гонконге / Казахстане** — нерезидент, посредник
- **Китайская фабрика (поставщик)** — получатель платежа

Операция:

1. Россия → агент: перевод средств
2. Агент → китайский поставщик: перевод

### 4.2 Юридическая структура

Есть два основных варианта:

#### 4.2.1 Договор поручения / агентский

Резидент заключает с агентом **договор поручения** или **агентский договор**, по которому агент обязуется перевести средства указанному получателю (китайскому поставщику).

**Плюс:** простая структура, типизирована в законодательстве.

**Минус:** для целей валютного контроля операция всё равно — ВЭД и попадает под 173-ФЗ.

#### 4.2.2 «Замена сторон» через уступку (assignment)

В контракте между резидентом и китайским поставщиком делается уступка — права получения платежа переходят к третьему лицу (агенту).

**Плюс:** платёж юридически идёт «нерезиденту», как если бы агент был поставщиком.

**Минус:** более сложная структура, требует сотрудничества китайского поставщика.

### 4.3 Существенные условия договора

Договор перевода через третье лицо должен включать:

- **Стороны:** резидент РФ (плательщик), агент-нерезидент (исполнитель), бенефициар-нерезидент (получатель)
- **Сумма:** в какой валюте, в каком размере
- **Целевое назначение:** оплата по контракту № X от Y
- **Идентификация бенефициара:** реквизиты китайского поставщика
- **Комиссия агенту:** обычно 2–7% от суммы
- **Сроки:** в какой срок агент должен перевести
- **Подтверждение:** агент должен предоставить подтверждение перевода
- **Возвраты:** что если перевод не получится
- **Форс-мажор:** включая развитие санкций
- **Применимое право:** обычно ОАЭ / Гонконг / Казахстан / Кыргызстан (не РФ)
- **Юрисдикция споров:** международный арбитраж

### 4.4 Аспекты соответствия

**173-ФЗ применимо:** да, операция всё равно валютная, требует УНК при превышении порога, СВО (справку о валютных операциях), репатриации в случае возврата.

**Налоговые соображения:**

- Комиссия агенту — расход компании, расход признаётся в учёте при наличии подтверждающих документов
- Возможны вопросы по трансфертному ценообразованию (ст. 105.16 НК РФ), особенно если агент в юрисдикции с низкими налогами
- НДС на услуги агента: применяется принцип места оказания услуг

**Проверка на санкции:**

- Агент должен быть проверен по санкционным спискам
- Китайский поставщик тоже проверен
- Периодическая повторная проверка — санкционные списки регулярно обновляются

### 4.5 Типовые ошибки

- **Неинформирование банка** о реальной природе платежа
- **Без должных подтверждающих документов** для налоговых целей
- **Высокая комиссия** агенту без обоснования — риск претензий по трансфертному ценообразованию
- **Зависимость от одного агента** — точка отказа
- **Без резервных маршрутов** — если агент терпит неудачу, всё стоит

**Ключевой вывод 4.** Договор перевода через третье лицо — легитимная структура при правильном оформлении. Соответствие 173-ФЗ обязательно, документация для налоговых / санкционных целей критична. Это не «обход санкций», а законное соглашение с третьей стороной, которое должно выдержать проверку.

## 5. Структура траншей

### 5.1 Зачем разбивать платёж

![](attachments/diagrams/06-tranche-structure.svg)

**Транши** — разбиение оплаты на несколько частей, синхронизированных с этапами производства / отгрузки / прибытия. Это распределяет риск между покупателем и продавцом.

Без траншей:

- 100% предоплата — весь риск у покупателя (что если продавец не поставит)
- 100% оплата по прибытии — весь риск у продавца (что если покупатель не заплатит)

С траншами — разделённый риск и согласованные стимулы.

### 5.2 Типовая структура 30-40-30

Самая распространённая структура для импорта из КНР:

- **Транш 1: 30% депозита** — при размещении заказа, для запуска производства
- **Транш 2: 40% промежуточного платежа** — при готовности товара (после QC-инспекции)
- **Транш 3: 30% остатка** — при отгрузке (или прибытии)

Это баланс между:
- Продавец получает депозит для запуска производства
- Продавец получает большую часть до отгрузки (стимул поставить качество)
- Покупатель удерживает остаток до проверки (защита от плохой партии)

### 5.3 Варианты структур

#### 5.3.1 Стандарт 30–40–30

Описано выше. Самый распространённый.

#### 5.3.2 30–70

- 30% депозит
- 70% остаток перед отгрузкой (после QC, при погрузке)

Подходит для меньших заказов или доверенных поставщиков.

#### 5.3.3 100% против документов

- 100% оплата при предъявлении документов (B/L, инвойс, сертификаты)
- Используется через L/C (Letter of Credit — аккредитив) или DP (Documents against Payment — документы против оплаты)

Подходит для новых или меньших поставщиков, где не хочется давать кредитные условия.

#### 5.3.4 Open Account / кредитные условия

- Товар отгружается, оплата через 30 / 60 / 90 дней после получения

Подходит для доверенных долгосрочных партнёров. Часто поддерживается Sinosure для китайского поставщика.

#### 5.3.5 Комбинации

В реальности часто комбинация: например, 30% депозит + аккредитив на 70%, или 30% / 40% / 30% с разными маршрутами.

### 5.4 Синхронизация с логистическими вехами

Транши синхронизируются с конкретными вехами:

| Транш | Веха | Документ-триггер |
|-------|------|---------|
| 1 (депозит) | Размещение заказа | Подтверждение заказа, PI (Proforma Invoice — проформа-инвойс) |
| 2 (промежуточный) | Производство завершено | Отчёт QC, фото, упаковка готова |
| 3 (остаток) | Отгрузка / прибытие | B/L, таможенная декларация, по выбору |

Иногда больше триггеров:

- 10% при заказе + 20% при готовности материалов + 40% при завершении производства + 30% при отгрузке

Чем больше траншей, тем сложнее операционно, но более гибкое распределение рисков.

### 5.5 ВКС — валютно-кассовое сопровождение

Многие банки предлагают **ВКС** — валютно-кассовое сопровождение — сервис, при котором банк сам управляет траншами и соответствием.

ВКС включает:

- Подготовка и регистрация контракта (УНК)
- Структуризация платежей
- Проверка соответствия каждого транша
- Документооборот
- Отчётность

Стоимость ВКС: 0,5–2% от объёма + фиксированные платежи. Для крупных операций это значительно дешевле, чем команда соответствия внутри компании.

**Ключевой вывод 5.** Структура траншей — переговорный параметр, распределяющий риск и денежный поток. Стандарт 30–40–30 работает для большинства случаев, но опытные импортёры оптимизируют под конкретных поставщиков и ситуации.

## 6. Юаневые расчёты — CNY против CNH

### 6.1 Два юаня

Существует **два юаня** с разными режимами:

#### 6.1.1 CNY — материковый ренминби

**CNY** (Chinese Yuan, onshore — материковый юань) обращается в КНР под жёстким государственным контролем.

**Особенности:**
- Используется только внутри материковой КНР
- Курс устанавливается Народным банком Китая
- Ограничения на конвертацию
- Капитальный контроль

#### 6.1.2 CNH — офшорный ренминби

**CNH** (Chinese Yuan offshore, Hong Kong — офшорный юань) обращается за пределами материковой КНР.

**Особенности:**
- Свободно обращается в Гонконге, Сингапуре, Лондоне
- Курс плавающий
- Без жёсткого капитального контроля
- Используется в международной торговле и финансовых операциях

### 6.2 Курсовые различия

CNY и CNH имеют **слегка различающиеся курсы** из-за разных режимов. Спред обычно небольшой, но в периоды волатильности может растягиваться.

В международных контрактах обычно указывается валюта:

- «CNY» — явно материковый
- «RMB» — может быть общим, нужно уточнить
- «CNH» — офшорный

### 6.3 Российские банки и расчёты в RMB

В РФ исторически использовался CNY (через специальные каналы). После 2022 года — массовый сдвиг к юаневым расчётам как основному маршруту.

**Банки с возможностью работы с КНР:**

- **ВТБ** — сильные отношения с банками КНР
- **Газпромбанк** — фокус на энергетике и крупном бизнесе с КНР
- **Россельхозбанк** — сельхоз
- **Альфа-Банк** — общий
- **МКБ** — активно растёт
- **Russian-Chinese Investment Bank** — специализированный

Эти банки могут открыть счета в RMB для клиентов и проводить операции через CIPS.

### 6.4 Хеджирование юаня

Юань имеет свою волатильность против рубля. Для крупных долгосрочных контрактов применяется хеджирование:

- **Forwards (форварды)** — лучше использовать через банки с возможностью работы с RMB
- **Swaps (свопы)** — менее доступны в РФ
- **Естественное хеджирование** — сопоставление доходов в RMB (если есть экспорт в КНР) с расходами в RMB

**Ключевой вывод 6.** Юаневые расчёты — основной маршрут для торговли с КНР. Различение CNY и CNH важно, банки с возможностью работы с RMB в РФ — ограниченный список, хеджирование доступно, но не развито. К 2025 году RMB представляет 30–50% российской ВЭД с КНР.

## Сводный практический протокол

При запуске контракта на импорт из КНР в 2025 году:

| Шаг | Действие |
|-----|----------|
| 1 | Выбрать банки (основной + резервный) для платежей в КНР |
| 2 | Открыть счёт в RMB в каждом |
| 3 | Проверить китайского поставщика на санкции |
| 4 | Решить: прямой маршрут или агентский |
| 5 | Если агентский — выбрать партнёра в ОАЭ / Гонконге / Казахстане |
| 6 | Заключить основной контракт с китайским поставщиком |
| 7 | Заключить агентский контракт (если применимо) |
| 8 | Постановка на УНК |
| 9 | Структурировать платежи в транши |
| 10 | Выполнить первую транзакцию (малую для теста) |
| 11 | Построить достаточную способность для регулярных операций |

Постоянные активности:

- Ежемесячный мониторинг обновлений санкций
- Поддержание банковских отношений
- Подготовка резервных маршрутов
- Отслеживание стоимости / времени для оптимизации

## Применение для руководителя

| Целевая роль | Что взять из заметки |
|--------------|---------------------|
| **CFO** | Стратегические решения по банкингу; управление валютным риском; хеджирование юаня; стоимость платёжных маршрутов (премия за санкции 2–7%) |
| **Директор закупок / ВЭД** | Операционное владение всеми маршрутами; банковские отношения; управление агентами; отслеживание транзакций |
| **Сотрудник по соответствию** | Регулярная проверка санкций; документация для каждого агентского контракта; постоянный мониторинг |
| **Главный бухгалтер** | Учёт операций через агентов; налоговые последствия трансфертного ценообразования; учёт по РСБУ операций в RMB |
| **COO** | Стратегическое понимание платёжного ландшафта; планирование устойчивости; отношения с поставщиками через надёжность платежей |
