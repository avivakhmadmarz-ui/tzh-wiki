# 05 — Таможенное оформление и логистика ВЭД

> Таможня — финальная точка ВЭД-операции, где собираются все документы, рассчитываются пошлины, проверяется соответствие. Понимание ТН ВЭД (10-значный код товара), документооборота, выбор брокера и таможенных процедур — критично для своевременного оформления. Ошибка в коде или документе может задержать груз на недели и стоить десятки тысяч рублей в штрафах.

## 1. Таможенная система ЕАЭС

### 1.1 Контекст

С 2018 года в РФ применяется **Таможенный кодекс ЕАЭС** (Евразийского экономического союза), который заменил Таможенный кодекс Таможенного союза. ЕАЭС включает РФ, Беларусь, Казахстан, Армению, Кыргызстан — единое таможенное пространство.

Главные регуляторы:

- **ФТС России (Федеральная Таможенная Служба)** — основной национальный регулятор
- **ЕЭК** (Евразийская Экономическая Комиссия) — наднациональный регулятор ЕАЭС
- **Министерство финансов РФ** — для налоговых аспектов

### 1.2 Главные функции таможни

- **Контроль перемещения товаров** через границу
- **Сбор пошлин и налогов** (импортная пошлина, НДС, акциз)
- **Защита экономических интересов** (антидемпинг, защитные меры)
- **Защита потребителей** (сертификация, безопасность)
- **Соответствие международным обязательствам** (санкции, конвенции)
- **Статистика** внешней торговли

### 1.3 Главные операции с таможней

Основные таможенные операции для импортёров:

- **Декларирование** при ввозе товаров
- **Уплата пошлин** и налогов
- **Документальный и физический контроль**
- **Выпуск товаров** для свободного обращения
- **Корректировка деклараций** при необходимости

### 1.4 Структура таможенного процесса

![](attachments/diagrams/06-customs-clearance-flow.svg)

Стандартный поток:

1. Прибытие на границу ЕАЭС (порт, погранпереход, ж/д станция, аэропорт)
2. Регистрация документов
3. Подача декларации на товары (ЭДТ — электронная декларация)
4. Уплата пошлин и налогов
5. Таможенный контроль (документальный, иногда физический, иногда лабораторный)
6. Выпуск товаров

Целевое время: 24 часа от регистрации декларации до выпуска для случаев «зелёного коридора». На практике может занимать дни / недели при осложнениях.

**Ключевой вывод 1.** Таможенный процесс — структурированный workflow с определёнными вехами. Понимание процесса позволяет планировать сроки и подготовиться к возможным задержкам.

## 2. ТН ВЭД — Товарная номенклатура

### 2.1 Что такое ТН ВЭД

![](attachments/diagrams/06-hs-code-structure.svg)

**ТН ВЭД ЕАЭС** (Товарная номенклатура внешнеэкономической деятельности Евразийского экономического союза) — система классификации товаров для таможенных целей. Основа — **HS (Harmonized System — гармонизированная система)** ВТО, расширенная для нужд ЕАЭС.

### 2.2 Структура кода

ТН ВЭД ЕАЭС — это **10-значный код**:

- **XX** (2 цифры) — раздел / группа (например, 84 = «Машины и оборудование»)
- **XXXX** (4 цифры) — товарная позиция (8471 = «Компьютеры»)
- **XXXXXX** (6 цифр) — субпозиция (международный уровень HS — 847130 = «портативные компьютеры до 10 кг»)
- **XXXXXXXXXX** (10 цифр) — национальный код ЕАЭС (847130 0001 — конкретная спецификация для таможенных целей)

### 2.3 Зачем нужен правильный код

Код ТН ВЭД определяет:

- **Ставку импортной пошлины** (от 0% до 30%+ в зависимости от товара)
- **Ставку НДС** (10% или 20% в зависимости от категории)
- **Акциз** (для отдельных категорий — алкоголь, табак, нефтепродукты)
- **Нетарифные меры** (квоты, лицензии)
- **Сертификационные требования** (сертификат соответствия, декларация о соответствии)
- **Применимость антидемпинговых мер**
- **Соответствие санкциям** (определённые товары запрещены к экспорту в РФ)

### 2.4 Как выбирать код

Процесс выбора кода:

1. **Общее описание товара** на основе его характеристик
2. **Идентификация раздела / группы** через указатель
3. **Выбор товарной позиции** в группе
4. **Выбор субпозиции и подсубпозиции**
5. **Выбор национального кода** (последние 4 цифры)
6. **Верификация** через реестр ФТС или предварительное решение

### 2.5 Предварительное решение

В сложных случаях можно запросить у ФТС **предварительное решение о классификации товаров**. Это формальное письмо с присвоенным кодом, действующее 3 года.

Преимущества:
- Юридическая защита при таможенном контроле
- Предсказуемость для операций
- Можно использовать для нескольких поставок

Недостатки:
- Время (срок до 90 дней)
- Стоимость (госпошлина небольшая)
- Может не быть в нужный момент

### 2.6 Распространённые ловушки

- **Неверный код** — самая частая таможенная ошибка
- **Неоднозначность классификации** — многие продукты могут подпадать под несколько кодов
- **Заниженная классификация** ради низкой ставки — рассматривается как нарушение
- **Изменения классификации** при регуляторных обновлениях

**Ключевой вывод 2.** Правильный код ТН ВЭД — основа таможенных операций. Ошибки в классификации — самая распространённая причина задержек, дополнительных пошлин, штрафов. Инвестиции в качественную классификацию (через квалифицированных брокеров или консультантов) окупаются многократно.

## 3. Документы для таможенного оформления

### 3.1 Обязательные документы

Стандартный пакет документов для таможенной декларации:

#### 3.1.1 Коммерческие

- **Контракт** (внешнеторговый контракт с поставщиком)
- **Инвойс** (commercial invoice) — цена, количество, вес, описание
- **Упаковочный лист** (packing list) — детальное описание упаковки
- **Спецификация** или **proforma invoice** (по необходимости)

#### 3.1.2 Транспортные

- **Bill of Lading (B/L — коносамент)** — для морского транспорта
- **Air Waybill (AWB — авианакладная)** — для воздушного
- **CMR** (Convention relative au contrat de transport international de Marchandises par Route — Конвенция о договоре международной дорожной перевозки) — для авто
- **ЖД накладная** — для железнодорожного
- **Мультимодальные транспортные документы** — для комбинированных перевозок

#### 3.1.3 Технические / разрешительные

- **Сертификат соответствия / Декларация о соответствии** — для регулируемых товаров
- **Сертификат происхождения** — для преференциальной торговли
- **Лицензии** — для лицензируемых товаров (оружие, dual-use — двойного назначения, медицинское)
- **Сертификат органа здравоохранения** — для продуктов питания, фармацевтики
- **Сертификат безопасности** — для электроники, химикатов

#### 3.1.4 Финансовые

- **Документы об уплате пошлин и НДС**
- **Документы валютного контроля** (информация по УНК)
- **Договоры со складами временного хранения** (СВХ)

### 3.2 Документы для специфических категорий

#### 3.2.1 Продукты питания и напитки

- Ветеринарный сертификат
- Фитосанитарный сертификат (для растительного происхождения)
- Сертификат органа здравоохранения страны происхождения

#### 3.2.2 Фармацевтика

- Регистрационное удостоверение (Минздрав РФ)
- GMP-сертификат производителя (Good Manufacturing Practice — надлежащая производственная практика)
- Сертификат происхождения

#### 3.2.3 Электроника

- Сертификат соответствия ЕАЭС
- Маркировка CE / EAC

#### 3.2.4 Химикаты

- SDS (Safety Data Sheet — паспорт безопасности материала)
- Сертификат соответствия безопасности
- Лицензия (для определённых категорий)

### 3.3 Качество документов

Таможня требует:

- Подлинники или юридически заверенные копии
- Переводы на русский (если оригинал на других языках)
- Апостиль или легализация (для документов из определённых стран)
- Согласованность всех документов (количества, описания, веса должны совпадать)

### 3.4 Типичные проблемы

- **Несоответствия между документами** (например, вес в инвойсе не совпадает с упаковочным листом)
- **Отсутствие переводов**
- **Поздняя подача** одного из документов
- **Несоответствие описания товара коду ТН ВЭД**
- **Ошибки в цене или валюте**

Каждая ошибка может задержать оформление на дни.

**Ключевой вывод 3.** Качество документов — главный фактор эффективности таможни. Предварительная проверка всех документов (через брокера или внутреннюю команду соответствия) предотвращает большинство задержек и штрафов.

## 4. Таможенная стоимость

### 4.1 Что такое таможенная стоимость

**Таможенная стоимость** — стоимость товара для таможенных целей, на которую начисляются пошлины и НДС. Это критический параметр.

### 4.2 Методы определения таможенной стоимости

ЕАЭС / ВТО предусматривают 6 методов в иерархическом порядке:

#### 4.2.1 Метод 1 — по стоимости сделки

Цена, фактически уплаченная или подлежащая уплате (на основе инвойса) + добавления:

- **Плюс** транспортные затраты до границы ЕАЭС
- **Плюс** страхование
- **Плюс** роялти / лицензионные платежи, если применимо
- **Плюс** «помощь» поставщику (если покупатель предоставил материалы / оснастку)

Это основной метод, применимый в более чем 90% случаев.

#### 4.2.2 Метод 2 — по стоимости сделки с идентичными товарами

Если метод 1 не применим, используется таможенная стоимость идентичных товаров, проданных в ту же страну за тот же период.

#### 4.2.3 Метод 3 — по стоимости сделки с однородными товарами

Похож на метод 2, но для однородных (не идентичных) товаров.

#### 4.2.4 Метод 4 — вычитания

Цена перепродажи в стране импорта минус разумная маржа и затраты.

#### 4.2.5 Метод 5 — сложения

Стоимость материалов + стоимость производства + разумная прибыль.

#### 4.2.6 Метод 6 — резервный

Комбинация приведённых методов или другие разумные подходы.

### 4.3 Таможенная верификация

ФТС может **оспорить** заявленную таможенную стоимость, особенно если:

- Цена значительно ниже рыночных ориентиров
- Существенные отличия от идентичного импорта продукта
- Подозрение в искусственном ценообразовании для избежания пошлин

В таких случаях требуется **обоснование** заявленной стоимости через документацию.

### 4.4 Сложности

- **Сделки со связанными сторонами** (между аффилированными компаниями) — особое внимание трансфертному ценообразованию
- **Валютные колебания** между датой контракта и датой таможенного оформления
- **Объёмные скидки** должны быть задокументированы
- **Бесплатные образцы** — нулевая стоимость требует обоснования

**Ключевой вывод 4.** Таможенная стоимость — главная основа для таможенных пошлин. Метод 1 (по стоимости сделки) применяется чаще всего. Документация, подтверждающая стоимость, критична при таможенной проверке.

## 5. Таможенный брокер

### 5.1 Кто такой таможенный брокер

**Таможенный брокер** (теперь официально «таможенный представитель») — лицензированная организация, осуществляющая таможенные операции от имени декларанта.

В РФ брокеры должны иметь специальную аккредитацию ФТС, финансовую гарантию и нанимать сертифицированных специалистов.

### 5.2 Что делает брокер

Главные сервисы:

- **Классификация** товаров (коды ТН ВЭД)
- **Подготовка таможенной декларации** (ЭДТ)
- **Подача документов**
- **Уплата таможенных пошлин** (часто от имени клиентов через специально заведённый счёт)
- **Связь с таможенными офицерами** во время инспекций
- **Разрешение споров** с таможней
- **Постоформление-корректировки**

### 5.3 Выбор брокера

Критерии:

- **Специализация** в отрасли / категории
- **История работы** — точность, скорость, разрешение проблем
- **Географический охват** — на каких таможенных постах работают
- **Цены** — фиксированная ставка, процент от пошлин, гибрид
- **Рекомендации** — поговорить с существующими клиентами
- **Технологический уровень** — современные брокеры предлагают клиентские порталы, отслеживание в реальном времени
- **Ликвидность / финансовое положение** (может потребоваться авансирование пошлин)

### 5.4 Модели ценообразования

Типичные платежи брокера:

- **Фиксированная ставка** за декларацию (3 000–15 000 руб. в зависимости от сложности)
- **Процент** от таможенных пошлин (1–3%)
- **Гибрид** — фиксированная ставка + процент

Для операций большого объёма часто согласовываются более низкие ставки.

### 5.5 Топ-брокеры в РФ

Крупные игроки:

- **STS Logistics** — крупный универсальный брокер
- **DHL Customs** — связан с логистикой DHL
- **AsstrA** — операции Беларусь / РФ / ЕС
- **TLT** (Trans Logistic Trans) — крупный российский брокер
- **Customs Rus** — широкий спектр сервисов
- **СЗЛК** (Северо-Западная Логистическая Компания)
- **Tradoria** — современный цифровой подход

Многие также имеют специализированных брокеров для определённых категорий (например, электроники, химикатов, фармацевтики).

### 5.6 Самостоятельное оформление

Компании со значительным объёмом могут настроить собственный таможенный отдел:

**Плюсы:**
- Ниже стоимость на единицу при масштабе
- Лучший контроль
- Построение внутренней экспертизы

**Минусы:**
- Инвестиции в специалистов, технологии, лицензии
- Нагрузка по соответствию
- Постоянные требования к обучению

Большинство среднего бизнеса предпочитает аутсорсинг брокеру.

**Ключевой вывод 5.** Выбор правильного брокера — критическое решение. Качественный брокер значительно снижает таможенное трение, плюс даёт консультативную ценность. Инвестиции в долгосрочные отношения с брокером дают накопительные выгоды.

## 6. Таможенные платежи

### 6.1 Структура таможенных платежей

При импорте платёж включает:

#### 6.1.1 Ввозная пошлина

Ставка зависит от кода ТН ВЭД (от 0% до 30%+).

#### 6.1.2 НДС

20% для большинства товаров, 10% для определённых (продукты, книги, детские товары).

Рассчитывается на: **таможенная стоимость + ввозная пошлина + акциз**.

#### 6.1.3 Акциз

Для определённых категорий — алкоголь, табак, топливо, автомобили. Специфические ставки.

#### 6.1.4 Таможенные сборы

Фиксированные административные платежи, скромная сумма (несколько тысяч рублей в зависимости от стоимости).

### 6.2 Пример расчёта

Импорт партии электроники:

- Цена контракта: 100 000 USD
- Транспортировка: 5 000 USD
- **Таможенная стоимость:** 105 000 USD (метод 1)

Конвертация в рубли по курсу ЦБ на дату декларирования: 105 000 × 95 = 9 975 000 руб.

- **Ввозная пошлина:** 5% × 9 975 000 = 498 750 руб.
- **Общая база пошлины:** 9 975 000 + 498 750 = 10 473 750 руб.
- **НДС:** 20% × 10 473 750 = 2 094 750 руб.
- **Сборы:** ~10 000 руб.

**Итого платежи:** ~2 603 500 рублей.

### 6.3 Способы оплаты

- **Авансовые платежи** на счёт ФТС — наиболее распространено
- **Поручительство банка** (банковская гарантия)
- **Поручительство третьего лица** (может быть брокер)
- **Залог имущества** (редко)

### 6.4 Возврат пошлин

В некоторых случаях пошлины могут быть возвращены:

- При реэкспорте товара
- При уничтожении некачественного товара
- При ошибках классификации (с постоформление-корректировкой)

Процедура долгая (3–6 месяцев), нужны подтверждающие документы.

**Ключевой вывод 6.** Таможенные платежи — значительная часть общей стоимости импорта (обычно 25–40% в зависимости от категории). Правильная классификация и корректный расчёт пошлин — критичны для контроля затрат.

## 7. Страхование груза

### 7.1 Зачем страхование груза

Груз может быть утрачен / повреждён в пути. Страхование защищает от финансовых потерь.

### 7.2 Виды покрытия

#### 7.2.1 ICC Clauses (Institute Cargo Clauses — оговорки Института страховщиков по грузам)

Стандарт международного страхования грузов:

- **Clauses (C)** — базовое покрытие (пожар, потопление и т.д.) — минимум для CIF
- **Clauses (B)** — более широкое покрытие
- **Clauses (A)** — все риски (за исключением конкретных) — максимум

С Инкотермс 2020 CIP требует Clauses (A); CIF — только Clauses (C).

#### 7.2.2 Дополнительные риски

- **Военные риски** — отдельное положение
- **Забастовки / пиратство** — обычно отдельно
- **Покрытие кражи** — может быть включено или отдельно

### 7.3 Выбор страховщика

Международные страховщики грузов:

- **Lloyd's of London** — исторический стандарт, синдицированное покрытие
- **AIG, Chubb, Allianz** — крупные коммерческие страховщики
- **Российские:** Согаз, Ингосстрах, Ресо-Гарантия — значительные практики страхования грузов

### 7.4 Процесс претензий

При инциденте:

1. Немедленно уведомить перевозчика
2. Уведомить страховщика письменно в установленный срок (обычно 7–15 дней)
3. Задокументировать ущерб / утрату (фото, отчёты сюрвейеров)
4. Подать претензию с подтверждающими документами
5. Страховщик расследует и платит (или отказывает)

Процесс может занять 1–6 месяцев.

**Ключевой вывод 7.** Страхование груза — относительно недорогая (обычно 0,1–0,5% от стоимости) защита от значительных потенциальных потерь. Для ценного груза и долгих маршрутов — обязательно.

## Сводный практический протокол

При новом импорте за 30 дней до прибытия:

| День | Действие |
|------|----------|
| –30 | Определить код ТН ВЭД, рассчитать оценку пошлин |
| –20 | Привлечь брокера, подготовить документацию |
| –14 | Организовать страхование груза |
| –7 | Проверить, что все документы готовы |
| –3 | Предварительная проверка с брокером |
| 0 (прибытие) | Подать декларацию |
| +1 | Таможенный контроль |
| +2–3 | Выпуск товара |
| +7 | Уплатить все пошлины (если не предоплачено) |
| +14 | Получить товар на склад |
| +30 | Постоформление-обзор, корректировки при необходимости |

## Применение для руководителя

| Целевая роль | Что взять из заметки |
|--------------|---------------------|
| **Директор импорта** | Полное владение таможенными процессами; управление брокером; дисциплина документации |
| **Финансовый директор** | Таможенные пошлины и НДС в расчётах стоимости; денежный поток для предоплаченных пошлин |
| **Юрист / Compliance** | Требования к документации; споры по коду ТН ВЭД; санкции в импортируемых товарах |
| **Главный бухгалтер** | Учёт таможенных пошлин; возврат НДС; документальный след |
| **COO** | Стратегические решения: брокер против внутренней службы, оптимизация таможенного процесса |
