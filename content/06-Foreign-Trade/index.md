# Модуль 06 — Внешняя торговля (ВЭД — внешнеэкономическая деятельность)

> После санкций 2022 года ВЭД для российских компаний перестала быть рутинной операционной функцией и превратилась в стратегическое поле боя: перестройка sourcing на КНР / Индию / Турцию, поиск работающих платёжных коридоров, кредиты Sinosure, параллельный импорт, валютный контроль под новым давлением. Этот модуль — практическое руководство по работающим в 2025 году схемам.

## Заметки модуля

1. **[[01-Incoterms-2020|01 Инкотермс 2020]]** — 11 правил международной торговли (EXW / FCA / FAS / FOB / CPT / CIP / CFR / CIF / DAP / DPU / DDP), переход рисков, таможенная оценка, выбор для разных видов транспорта
2. **[[02-Currency-Control|02 Валютный контроль РФ]]** — 173-ФЗ, Инструкция Банка России 181-И, постановка контракта на учёт (УНК — уникальный номер контракта), КВВО (коды видов валютных операций), репатриация выручки, ст. 15.25 КоАП РФ (штрафы)
3. **[[03-Payment-Routes|03 Платёжные коридоры]]** — ОАЭ / Гонконг / Казахстан / Армения как маршруты обхода санкций, агентские схемы, договоры на перевод средств третьим лицам, транши, юаневые расчёты (CNY против CNH), CIPS (Cross-Border Interbank Payment System — китайская трансграничная межбанковская платёжная система), СПФС (Система передачи финансовых сообщений Банка России)
4. **[[04-China-Specifics|04 Китайская специфика]]** — типы поставщиков (OEM — Original Equipment Manufacturer — производитель по заказу / ODM — Original Design Manufacturer — производитель с собственным дизайном / JDM — Joint Design Manufacturer — совместный дизайн / factory — фабрика против trading — торговой компании), Sinosure (中国出口信用保险公司 — Китайская корпорация экспортного и кредитного страхования), контроль качества и AQL (Acceptable Quality Limit — приемлемый уровень качества), договор с фабрикой, защита интеллектуальной собственности
5. **[[05-Customs-and-Logistics|05 Таможенное оформление и логистика]]** — ТН ВЭД ЕАЭС (10-значный код на основе HS — Harmonized System — гармонизированной системы), документы (инвойс, упаковочный лист, B/L — Bill of Lading — коносамент, CMR — международная транспортная накладная), сертификация, выбор брокера, специфика ЕАЭС (Евразийский экономический союз)
6. **[[06-Parallel-Import|06 Параллельный импорт]]** — Постановление №506 (2022), список Минпромторга, разрешённые категории, операционные особенности, риски гарантии и сервиса

## Зачем модуль руководителю

ВЭД для российских компаний после 2022 года — это:

- 70%+ операционных компаний работают с импортом
- Прерывание привычных каналов: ушли западные банки, отключение от SWIFT крупнейших российских банков, уход брендов
- Новые маршруты: платежи через третьи страны (ОАЭ / Гонконг / Казахстан / Армения), юаневые расчёты, кредиты Sinosure
- Параллельный импорт как государственно поддерживаемый инструмент
- Постоянно меняющаяся регуляторика (валютный контроль ужесточается; параллельный импорт расширяется)

Руководитель без личного владения этими темами обречён на провайдеров / консультантов с риском недоверия и завышенных тарифов. Зрелое понимание модуля даёт стратегические преимущества в выборе каналов, заключении контрактов, переговорах с поставщиками и банками.

## Применение для руководителя

| Целевая роль | Что взять из модуля |
|--------------|---------------------|
| **Директор закупок / импорта** | Полный набор практических знаний: Инкотермс, валютный контроль, платёжные коридоры, sourcing в КНР, таможня, параллельный импорт — ежедневное владение |
| **COO** | Стратегические решения по географии sourcing; устойчивость платёжной инфраструктуры; интеграция ВЭД с цепочкой поставок |
| **CFO / Финансовый директор** | Валютные риски, экономика платёжных коридоров (2–7% комиссии), инструменты торгового финансирования (Sinosure, аккредитивы), соответствие 173-ФЗ |
| **Юрист** | Контракты с китайскими фабриками; договоры на перевод средств третьим лицам; соответствие санкциям; правовая рамка параллельного импорта |
| **Главный бухгалтер** | Операционка валютного контроля, КВВО, СВО (справки о валютных операциях), СПД (справки о подтверждающих документах), отражение в учёте |

## Источники

### Книги (приоритет чтения)

- ICC, **«Incoterms 2020 Rules»** (International Chamber of Commerce — Международная торговая палата, 2019) — официальный текст; единственный авторитетный источник по Инкотермс
- Frederick Newing, **«Trade Finance: Principles and Practice»** (Routledge) — полное руководство по торговому финансированию
- Mike Bellamy, **«The Essential Reference Guide to China Sourcing»** (China Sourcing Information Center) — практическое руководство для sourcing в КНР
- Carolyn Blackman, **«China Business Etiquette»** — культурные аспекты
- Eric T. Lin, **«Inside China Manufacturing»** — операционная специфика
- Renaud Anjoran, **«Importing from China in 7 Steps»** (Quality Inspection Tips) — практическое
- ICC, **«UCP 600»** (Uniform Customs and Practice for Documentary Credits — Унифицированные правила и обычаи для документарных аккредитивов) — для аккредитивов

### Российские источники

- **173-ФЗ «О валютном регулировании и валютном контроле»** (от 10.12.2003) — основной закон валютного контроля
- **Инструкция Банка России 181-И** (от 16.08.2017) — постановка контрактов на учёт
- **КоАП РФ, статья 15.25** — ответственность за нарушения валютного законодательства
- **Постановление Правительства РФ №506** (от 29.03.2022) — параллельный импорт
- **Приказы Минпромторга** — список товаров для параллельного импорта (обновляется ежеквартально)
- **Таможенный кодекс ЕАЭС** (от 01.01.2018) — таможенное регулирование
- **ТН ВЭД ЕАЭС** — Товарная номенклатура внешнеэкономической деятельности
- Учебники: **Б.А. Малышев, «Внешнеэкономическая деятельность»** (различные издательства РФ)
